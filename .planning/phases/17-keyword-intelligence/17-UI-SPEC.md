## Interaction Contract

### 1. Niche Skoru Sütunu (cluster header satırı)

- Cluster header (`bg-secondary/40 px-3 py-3`) satırına yeni sütun eklenir: sağdan ikinci konum, `ClusterDeleteButton`'ın solunda.
- Genişlik: `w-24 shrink-0`, metin hizası: `text-right`.
- Değer hesaplanmamışsa (skor `null`): `<span className="text-sm text-muted-foreground">—</span>` gösterilir. Skeleton animasyonu kullanılmaz (CONTEXT.md Claude's Discretion → Claude karar verir: dash tercih edilir, sayfa SSR olduğu için hesaplanmış skor DB'den doğrudan gelir veya henüz hesaplanmamıştır).
- Değer mevcutsa: `ScoreBadge` bileşeni — mevcut implementasyon değiştirilmez.
  - ≥ 70: `bg-violet-500/20 text-violet-400 text-xs border-0`
  - ≥ 40: `bg-amber-500/20 text-amber-400 text-xs border-0`
  - < 40: `bg-secondary text-muted-foreground text-xs border-0`
- Skor ondalık gösterimi: `score.toFixed(1)` — örn. "72.4"

### 2. Revenue Sütunu (cluster header satırı)

- Cluster header satırına yeni sütun eklenir: Niche Skoru sütununun solunda, cluster_name ve IntentBadge'in sağında.
- Genişlik: `w-28 shrink-0`.
- Otomatik atanan değer gösterilir. Kullanıcı dropdown ile override edebilir.
- Override dropdown (RevenueOverrideSelect):
  - Trigger: `RevenueBadge` bileşeninin kendisi tıklanabilir olur — hover'da underline veya `cursor-pointer` eklenir.
  - Seçenekler: `bilgi`, `mixed`, `ticari` (3 seçenek).
  - Seçim anında `updateClusterRevenue(clusterId, newRevenue, projectId)` server action çağrılır.
  - Action başarılıysa `revalidatePath` ile sayfa güncellenir — optimistic state gerekmez, SSR sayfası hızlı döner.
  - Action hatalıysa toast veya inline hata gösterilmez; konsola log düşer, sayfa state bozulmaz.

### 3. Niche Skoruna Göre Sıralama

- Cluster listesi varsayılan sıralamada `total_volume DESC` kullanmaya devam eder (mevcut `page.tsx` sorgusu).
- Sıralama client-side değil, URL searchParam üzerinden yapılır: `?view=cluster&sort=niche_score&dir=desc`.
- Sütun başlığı `<button>` olarak render edilir, tıklanınca `router.push` ile sort parametresi güncellenir.
- Sıralama aktifken başlık yanında `↑` veya `↓` karakteri gösterilir (HugeIcon yoksa unicode yeterli).
- İlk tıkta `desc`, ikinci tıkta `asc`, üçüncü tıkta sıralamayı kaldır (`sort` param silinir, default'a dön).

### 4. RevenueBadge Renk Kodu

```
bilgi    → bg-emerald-500/20 text-emerald-400   label: "Bilgi"
mixed    → bg-yellow-500/20 text-yellow-400     label: "Mixed"
ticari   → bg-red-500/20 text-red-400           label: "Ticari"
null     → <span className="text-sm text-muted-foreground">—</span>
```

className direkt atama — variant prop kullanılmaz (STATE.md proje kararı).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Niche Skoru sütun başlığı | "Niche Skoru" |
| Revenue sütun başlığı | "Revenue" |
| Niche Skoru null durumu | "—" (dash, tooltip yok) |
| Revenue null durumu | "—" (dash, dropdown trigger'dan manuel atanabilir) |
| Revenue dropdown placeholder | "Tür seç" |
| Revenue dropdown seçenek 1 | "Bilgi" |
| Revenue dropdown seçenek 2 | "Mixed" |
| Revenue dropdown seçenek 3 | "Ticari" |
| Sıralama sütun başlığı (sıralı değil) | "Niche Skoru" |
| Sıralama sütun başlığı (desc aktif) | "Niche Skoru ↓" |
| Sıralama sütun başlığı (asc aktif) | "Niche Skoru ↑" |

Bu fazda yıkıcı aksiyon yoktur — cluster silme mevcut fazın kapsamında değil. Override dropdown'da onay diyalogu gerekmez; kullanıcı dropdown'ı yeniden açarak değeri değiştirebilir.

Empty state (cluster yoksa): Mevcut ClusterPanel boş durum metni değiştirilmez:
- Başlık yok, yalnızca `text-sm text-muted-foreground` iki satır:
  - "Henüz küme oluşturulmadı."
  - "'Kümelere Böl' butonuna basarak keyword'leri otomatik gruplandır."
