# Phase 12 — UI Design Contract

> Visual and interaction contract for Phase 12: Content Studio.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui v4 |
| Preset | base-mira (from components.json) |
| Component library | @base-ui/react (NOT @radix-ui) |
| Icon library | hugeicons (free tier) |
| Font | Geist Sans (--font-sans) / Geist Mono (--font-mono) |

**Critical constraints (locked from prior phases):**
- Tailwind v4 CSS-first: `tailwind.config.ts` yoktur. Tüm tema özelleştirmeleri `globals.css` CSS custom property olarak yazılır.
- Dark mode: `html` elementinde statik `className="dark"` — toggle yok, light mode render edilmez.
- `font-medium` class YASAKTIR. Ağırlık geçişi için `font-normal` (400) ve `font-semibold` (600) kullanılır.
- `Badge`: `variant` prop kullanılmaz — renk `className` ile doğrudan atanır.
- `DialogTrigger`: `asChild` kullanılmaz — `render={<Button />}` prop pattern kullanılır.

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | İkon gap'leri, badge iç padding |
| sm | 8px | Buton iç padding, kart içi sıkışık boşluk |
| md | 16px | Varsayılan element spacing, kart padding |
| lg | 24px | Bölüm kartları arası gap, header padding |
| xl | 32px | Layout gap, bölüm grupları arası |
| 2xl | 48px | Sayfa üst/alt padding |
| 3xl | 64px | Sayfa düzeyinde büyük boşluk (footer gap) |

Exceptions:
- Touch target minimum 44px (onay/ret butonları için min-h-[44px])
- Streaming cursor animasyon alanı: kart içinde min-h-[120px] rezerve edilir

## Layout Contract

### Content Studio Sayfa Yapısı

```
┌─────────────────────────────────────────────────┐
│  STICKY HEADER (Slate 900, border-b Slate 800)   │
│  ← Geri    Sayfa Adı — İçerik Stüdyosu          │
│  [3/7 bölüm onaylandı]    [Tümünü Üret]         │
├─────────────────────────────────────────────────┤
│                                                   │
│  SCROLLABLE SECTION CARD LIST                    │
│  (padding: 24px, gap: 16px)                      │
│                                                   │
│  ┌─── BÖLÜM KARTI ──────────────────────────┐   │
│  │ [DURUM BADGE]  H2: Başlık Metni          │   │
│  │ ──────────────────────────────────────── │   │
│  │ [İçerik alanı — textarea veya metin]     │   │
│  │                                           │   │
│  │ [Yeniden Üret]         [Reddet] [Onayla] │   │
│  └──────────────────────────────────────────┘   │
│                                                   │
└─────────────────────────────────────────────────┘
```

### Sticky Header (sabit üst bölge)

- `position: sticky; top: 0; z-index: 10`
- Arka plan: `var(--card)` (#0f172a Slate 900)
- Alt kenarlık: `border-b border-border`
- Padding: 16px yatay, 12px dikey
- İçerik: Sol → geri butonu + sayfa başlığı; Sağ → progress badge + "Tümünü Üret" butonu

### Bölüm Kartı — Durum Görünümleri

Her bölüm kartı `Card` bileşeni kullanır (`var(--card)` zemin). Durum farkı sol kenarlık ile ifade edilir:

| Durum | Sol Kenarlık | Açıklama |
|-------|-------------|----------|
| `pending` | `border-l-4 border-slate-700` | Henüz üretim başlamadı |
| `generating` | `border-l-4 border-blue-500` | Aktif stream akıyor |
| `draft` | `border-l-4 border-slate-500` | Üretim tamamlandı, onay bekliyor |
| `approved` | `border-l-4 border-emerald-400` | Onaylandı (görsel ayrım belirgin) |
| `rejected` | `border-l-4 border-red-500` | Reddedildi |

**Kart iç yapısı:**

1. **Başlık satırı:** `[Durum Badge]` + `H2: {heading metni}` (font-semibold 16px)
2. **Ayırıcı:** `<Separator />`
3. **İçerik alanı:**
   - `pending`: "Bu bölüm henüz üretilmedi." gri metin (muted-foreground)
   - `generating`: Streaming metin + yanıp sönen cursor (`animate-pulse` ile `▋`)
   - `draft` veya `rejected`→`pending`: Düzenlenebilir `<Textarea />` (min-h-[120px])
   - `approved`: Düzenlenebilir olmayan metin alanı (readonly, bg muted)
4. **Aksiyon satırı:** Sol → "Yeniden Üret" butonu; Sağ → "Reddet" + "Onayla" butonları
   - `approved` durumunda: Sağda yalnızca "Yeniden Üret" (onayı geri almak için)

### Progress Göstergesi

Header sağ bölümünde, "Tümünü Üret" butonunun solunda:

- Format: `{n}/{total} bölüm onaylandı` — Badge bileşeni ile
- Badge `className`: tüm onaylandıysa `bg-emerald-500/20 text-emerald-400`, aksi hâlde `bg-slate-800 text-slate-400`
- Tümü onaylandığında badge metni: `Tüm bölümler onaylandı`

### "Tümünü Üret" Butonu Durumları

| Durum | Görünüm |
|-------|---------|
| Hazır (hiç üretilmemiş) | Primary variant, "Tümünü Üret" etiketi |
| Üretim sürüyor | Disabled, "Üretiliyor... ({n}/{total})" etiketi + spinner |
| Tüm bölümler onaylı | Secondary variant, "Yeniden Tümünü Üret" etiketi |

### HTML Çıktısı Hazır Bildirimi

Tüm bölümler onaylandığında sayfanın alt kısmında beliren bildirim kartı:

- Arka plan: `bg-emerald-500/10 border border-emerald-500/30`
- İkon: Hugeicons `tick-02` (emerald-400)
- Başlık: "HTML Çıktısı Hazır" (font-semibold, emerald-400)
- Açıklama: "Tüm bölümler onaylandı. İçerik WordPress'e yayınlanmaya hazır."
- Bu bildirim `position: sticky; bottom: 0` ile görünür kalır

### Entry Point — Sayfa Listesi

`/projeler/[id]/sayfa-paketi/page.tsx` sayfasındaki her satırda:
- Paket status = `locked` ise: "İçerik Üret" butonu görünür (secondary variant, HugeIcons `edit-02` ikon)
- Paket status = `locked` değilse: "İçerik Üret" butonu render edilmez

### Destructive Aksiyon
- **Ret (Reddet):** Onay dialogu yoktur — doğrudan uygulanan düşük riskli aksiyondur. Bölüm `rejected` durumuna geçer, kullanıcı hemen "Yeniden Üret" yapabilir. Kalıcı veri kaybı yoktur.

## State Machine Referansı

Bölüm durum geçişleri (executor'ın uygulayacağı sıra):

```
pending ──[Üret]──▶ generating ──[stream tamamlandı]──▶ draft
  ▲                                                        │
  │                                          ┌────[Reddet]─┘
  └────────────────[rejected→pending]────────┘
                                              │
                                          [Onayla]
                                              │
                                              ▼
                                          approved ──[Yeniden Üret]──▶ pending
```

Tüm bölümler `approved` olduğunda → `html_content` otomatik birleştirilir → `HtmlReadyBanner` görünür.

## Interaction Contracts

### Paralel Streaming

- "Tümünü Üret" tıklandığında TÜM bölümler aynı anda `generating` durumuna geçer.
- Her bölüm kartı bağımsız SSE veya ReadableStream'den token alır.
- Bir bölümün stream'i biterken kullanıcı başka bölümü onaylayabilir.
- "Tümünü Üret" butonu disabled kalır; içinde progress sayacı güncellenir.

### Inline Düzenleme

- `draft` durumundaki `<Textarea />` doğrudan düzenlenebilir.
- "Onayla" tıklandığında textarea içeriği (düzenlenmiş hâliyle) `content_sections[i].content` olarak kaydedilir.
- Auto-save yoktur — sadece "Onayla" ile kayıt yapılır.

### Onay Kaydı

- Her "Onayla" aksiyonu bir Server Action'dır: `approveSection(pageId, sectionIndex, content)`.
- Action: `content_sections` JSONB günceller → `revalidatePath()`.
- Tüm bölümler `approved` ise aynı action HTML birleştirmeyi de tetikler.

### Scroll Davranışı

- Yeni bir bölümün üretimi başladığında o karta otomatik scroll yapılmaz — kullanıcı akışı bozmaz.
- Sticky header sayfa scroll edildiğinde sabit kalır.
- HTML Ready banner sayfa altında sticky olarak görünür.

## Accessibility

- Her bölüm kartı `<article>` veya `<section>` element olarak işaretlenir; `aria-label="{heading metni} bölümü"` atanır.
- Streaming sırasında kart `aria-busy="true"` taşır.
- "Onayla" butonu için `aria-label="'{heading}' bölümünü onayla"` kullanılır.
- "Reddet" butonu için `aria-label="'{heading}' bölümünü reddet"` kullanılır.
- Progress badge: `aria-live="polite"` ile ekran okuyucuya güncelleme iletilir.
