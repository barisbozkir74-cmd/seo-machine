## Spacing Scale

Mevcut Tailwind token örüntüsünden türetildi. Bu fazda yeni spacing token tanımlanmaz.

| Token | Tailwind class | Pixel karşılık | Kullanım yeri |
|-------|---------------|----------------|---------------|
| xs | gap-1 / p-1 | 4px | İkon boşlukları, inline badge padding |
| sm | gap-2 / px-2 py-1 | 8px | Kompakt satır elemanları, buton gap'leri |
| md | px-3 py-2 | 12px / 8px | Dialog satır padding, header cell padding |
| lg | px-3 py-3 | 12px / 12px | Dialog header/footer padding |
| xl | px-6 py-3 | 24px / 12px | Toolbar container padding |
| 2xl | p-8 | 32px | Sayfa-level padding |

**Exceptions:**
- 12px (px-3/py-2, px-3/py-3) — mevcut projenin compact satır padding'i; tüm dialog row'ları bu değeri kullanır.
- Toolbar buton yüksekliği: h-9 = 36px (Button default, touch target).
- Dialog max-w-2xl = 672px — GeneratePagesDialog mevcut değeri korunur.
- Dialog iç scroll: `max-h-96` (384px) — mevcut dialog'dan alınır.

## "Sistemi Kur" Toolbar Butonu

### Placement

"Sistemi Kur", `KeywordStratejisiToolbar`'da `StratejiOnaylaButton`'un **sağına** eklenir.

```
// Toolbar sırası (soldan sağa):
[ClusterButton] [StratejiOnaylaButton] [SistemiKurButton]
```

### İki Durum

**Durum 1 — Disabled (isStrategyApproved = false):**

```tsx
<Button
  variant="ghost"
  disabled
  className="h-9 text-xs opacity-40 cursor-not-allowed"
  title="Önce stratejiyi onaylayın"
>
  Sistemi Kur
</Button>
```

Tooltip metni: `"Önce stratejiyi onaylayın"` — native `title` attribute yeterli (shadcn Tooltip bileşeni eklenmez).

**Durum 2 — Aktif (isStrategyApproved = true):**

```tsx
<Button
  variant="default"
  className="h-9 text-xs"
  onClick={() => setDialogOpen(true)}
>
  Sistemi Kur
</Button>
```

`variant="default"` = filled, primary renk. StratejiOnaylaButton ile görsel ayrışım: StratejiOnaylaButton onaylandığında ghost+emerald olur; SistemiKurButton filled/primary ile akışın bir sonraki adımına dikkat çeker.

## GeneratePagesDialog Değişiklikleri

### alreadyExists Satır Davranışı (D-03, D-08)

**Önceki davranış (Phase 20 öncesi):**
- `disabled = r.alreadyExists || isPending`
- Checkbox disabled, input disabled

**Yeni davranış (Phase 21):**
- `disabled = isPending` (alreadyExists tek başına disable etmez)
- Checkbox aktif — kullanıcı "Dahil Et" ile overwrite kararı verir
- "Zaten var" badge korunur (amber, uyarı rengi)
- `include = false` → default (değişmez — mevcut initialState logic'i)
- `include = true + alreadyExists = true` → satır amber highlight alır

### Satır CSS Kuralı

| Durum | className |
|-------|-----------|
| alreadyExists = false, include = true | `''` (renksiz) |
| alreadyExists = false, include = false | `''` (renksiz) |
| alreadyExists = true, include = false | `'bg-amber-500/10'` |
| alreadyExists = true, include = true | `'bg-amber-500/10'` (aynı — badge yeterli uyarıyı verir) |

**Input disabled kuralı:** Input ve select yalnızca `isPending` durumunda disabled olur. alreadyExists satırlar include=false iken input görsel olarak `opacity-50` değil; tam opaklık — kullanıcı ismi düzenleyebilir (include=true yaparsa payload'a düzenlenen isim gider).

### Footer Button Label (D-08)

Her zaman: `"Oluştur / Güncelle"` — `isPending` sırasında: `"Oluşturuluyor…"` (değişmez).

### Footer Sayaç Copy

```
// include count — overwrite/yeni ayrımı footer'da gösterilmez (basitlik)
"{includedCount} sayfa {hasOverwrite ? 'oluşturulacak / güncellenecek' : 'oluşturulacak'}"
```

`hasOverwrite` = `state.some((r, i) => r.include && rows[i].alreadyExists)`

### Payload Değişikliği

```tsx
payload.push({
  clusterId: rows[i].clusterId,
  pageName: state[i].pageName.trim(),
  pageType: state[i].pageType,
  focusKeywordId: rows[i].focusKeywordId,
  overwrite: rows[i].alreadyExists ? true : undefined,  // D-03
})
```

### Başarı Sonrası (D-04)

Dialog kapandıktan sonra:
1. Toast gösterilir (shadcn toast veya basit state toast — mevcut pattern'e uygun)
2. `router.push('/projeler/${projectId}/site-blueprint')`

Toast pattern mevcut projede `sonner` veya inline state'e bakılır; başarı mesajı aşağıdaki copy contract'ta tanımlandı.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA — aktif | Sistemi Kur |
| Primary CTA — disabled | Sistemi Kur (aynı, opacity ile pasifleşir) |
| Disabled tooltip | Önce stratejiyi onaylayın |
| Dialog başlığı | Kümelerden Sayfa Oluştur |
| Dialog footer butonu | Oluştur / Güncelle |
| Dialog footer butonu — pending | Oluşturuluyor… |
| Dialog footer sayaç — overwrite yok | {N} sayfa oluşturulacak |
| Dialog footer sayaç — overwrite var | {N} sayfa oluşturulacak / güncellenecek |
| "Zaten var" badge | Zaten var |
| İptal butonu | İptal |
| Başarı toast — sadece yeni | {created} sayfa oluşturuldu |
| Başarı toast — yeni + güncelleme | {created} sayfa oluşturuldu, {updated} güncellendi |
| Başarı toast — sadece güncelleme | {updated} sayfa güncellendi |
| Hata — sayfa adı boş | "{clusterName}" için sayfa adı boş olamaz. |
| Hata — action başarısız | Sayfa oluşturma başarısız. Lütfen tekrar deneyin. |
| Empty state (0 approved cluster) | Onaylanmış küme bulunamadı. Önce keyword stratejisi sayfasından kümeleme yapın. |

**Destructive actions:** Bu fazda destructive action yoktur. overwrite=UPDATE (sil+yeniden oluştur değil) — confirmation dialog gerekmez (D-03).
