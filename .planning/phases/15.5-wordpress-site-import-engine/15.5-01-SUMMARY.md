## Schema Summary

### New Table: `project_imported_pages`

| Column | Type | Notes |
|--------|------|-------|
| id | UUID PK | gen_random_uuid() |
| project_id | UUID FK | REFERENCES projects(id) ON DELETE CASCADE |
| wp_id | INTEGER | WP post/page ID |
| wp_type | TEXT CHECK | page/post/category/tag |
| title | TEXT NOT NULL | — |
| slug | TEXT | nullable |
| link | TEXT | public WP URL |
| parent_wp_id | INTEGER | 0=root, null=kök |
| wp_created_at / wp_modified_at | TIMESTAMPTZ | nullable |
| content_summary | TEXT | max 200 char, AI-filled |
| primary_intent | TEXT CHECK | informational/commercial/transactional/navigational |
| gsc_clicks / gsc_impressions / gsc_avg_position | INTEGER/NUMERIC | nullable, GSC join |
| flag_orphan | BOOLEAN NOT NULL DEFAULT false | — |
| flag_weak_page | BOOLEAN | nullable (no GSC = NULL — D-10) |
| flag_outdated | BOOLEAN NOT NULL DEFAULT false | — |
| flag_missing_metadata | BOOLEAN NOT NULL DEFAULT false | — |
| flag_missing_keyword | BOOLEAN NOT NULL DEFAULT false | — |
| flag_duplicate_intent | BOOLEAN NOT NULL DEFAULT false | — |
| imported_at / updated_at | TIMESTAMPTZ NOT NULL | — |
| UNIQUE | (project_id, wp_id) | upsert target — D-09 |

### Index
- `idx_imported_pages_project` ON project_imported_pages(project_id)
