## What Was Built

### Task 1: POST /api/wp/import

Uzun-süreli WP import pipeline'ını çalıştıran Route Handler. Pipeline sırası:

1. Body parse + validation (`projectId`, `userId`)
2. Service role client oluşturma
3. IDOR koruması: `projects.user_id = userId` ownership check (T-15.5-06-01)
4. WP credentials: `getWordPressCredentials(projectId)` — Supabase Vault
5. `import_status = 'running'`, `import_current = 0`, `import_total = 0`
6. D-08 endpoint loop: `pages → posts → categories → tags`
7. Her endpoint: `fetchAllWpContent` + `normalizeWpPage` + progress güncelleme
8. Toplu upsert (200'lük batch, `onConflict: 'project_id,wp_id'`) — D-09
9. Pitfall 7: WP'de silinen sayfalar `flag_orphan=true` (500'lük batch)
10. GSC matching: `matchGscData` (userId ile) + `enrichWithGscMetrics` upsert
11. Faz A audit flags: `computeAuditFlags` per-page DB update
12. `import_status = 'enriching'`
13. AI enrichment: `enrichImportedPages` (claude-haiku-4-5, BATCH_SIZE=20)
14. Faz B: `computeDuplicateIntentFlags` → `flag_duplicate_intent` update
15. `import_status = 'complete'`, `import_completed_at = now()`

Hata durumunda: `import_status = 'error'`, hata loglanır (credentials loglanmaz — T-15.5-06-02).

### Task 2: GET /api/wp/import-status

Client polling endpoint. Güvenlik:
- `createClient().auth.getUser()` ile session doğrulama (T-15.5-06-03)
- `.eq('user_id', user.id)` ownership check — başkasının projesini okuma engellendi

Response formatı:
```json
{ "status": "running|enriching|complete|error|idle", "current": 42, "total": 156 }
```

`import_status ?? 'idle'` null-coerce: henüz import başlatılmamış projeler için.

## Deviations from Plan

**1. [Rule 2 - Missing Critical Functionality] Upsert batch boyutu eklendi**
- **Found during:** Task 1 implementation
- **Issue:** Plan'da tek `upsert()` call vardı; büyük sitelerde (200+ sayfa) Supabase payload limiti aşılabilir
- **Fix:** 200'lük upsert batch + 500'lük orphan marking batch eklendi
- **Files modified:** src/app/api/wp/import/route.ts

**2. [Rule 2 - Missing Critical Functionality] matchGscData userId parametresi**
- **Found during:** Task 1 — gsc-match.ts interface incelemesi
- **Issue:** Plan'daki kod örneğinde `matchGscData(projectId, project.gsc_property_url)` — userId eksikti; ancak `gsc-match.ts` imzası userId'yi token ownership için zorunlu kılıyor
- **Fix:** `matchGscData(projectId, project.gsc_property_url, userId)` olarak düzeltildi
- **Files modified:** src/app/api/wp/import/route.ts
