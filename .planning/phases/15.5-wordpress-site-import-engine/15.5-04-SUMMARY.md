## Implementation Details

### audit-flags.ts

`computeAuditFlags(input: AuditFlagInput): AuditFlagOutput`

| Flag | Logic |
|------|-------|
| `flag_weak_page` | `null` if GSC data absent; `true` if clicks < 10 AND avg_position > 20 (D-10) |
| `flag_outdated` | `wp_modified_at` older than 12 months (D-11) |
| `flag_orphan` | `flag_orphan_deleted === true` (D-12) |
| `flag_missing_metadata` | Yoast title/desc absent AND native title/excerpt absent (D-13 + Pitfall 3) |
| `flag_missing_keyword` | None of project_keywords appear as URL segment in page_link (A5) |

`computeDuplicateIntentFlags(pages)` — Faz B: counts same `primary_intent` across project pages, returns `wp_id → boolean` map.

### gsc-match.ts

`matchGscData(projectId, gscPropertyUrl, userId?)` — Direct Search Analytics API call for last 28 days, page dimension. Returns `Map<normalizedUrl, GscPageMetric>` or `null` for:
- `gscPropertyUrl === null` (GSC not connected)
- `gscPropertyUrl.startsWith('sc-domain:')` (Pitfall 5 guard)
- Token unavailable

`enrichWithGscMetrics(pages, gscMap)` — Maps imported pages array to GSC metric objects via normalized URL lookup.

### url-normalize.ts

`normalizeUrl(url: string): string` — http→https, www removal, trailing slash removal, query string and fragment removal.
