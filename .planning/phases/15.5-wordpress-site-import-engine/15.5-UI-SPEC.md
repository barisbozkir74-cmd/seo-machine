| Token | Value | Usage |

| xs | 4px | Icon gap, badge padding, tree row inline gap |
| sm | 8px | Button gap, chip gap, inline element spacing |
| md | 16px | Default section spacing, tree base indent (`pl-4`) |
| lg | 24px | Major element separation |
| xl | 32px | Section breaks |
| 2xl | 48px | — |
| 3xl | 64px | — |

**Exceptions:**
- Touch target minimum: 44px yükseklik (`min-h-[44px]`) — "WordPress Sitemi İçeri Al" import butonu ve "Site Analizine Git" butonu.

- Badge padding: `px-2 py-0.5` — audit flag badge'leri için tutarlı.
- Progress bar yüksekliği: 8px (`h-2`) — inline progress için.

## Interaction States

### SiteImportSection — Import Akışı

| Durum | Görsel | Davranış |
|-------|--------|---------|
| **idle (WP bağlı değil)** | Bölüm gizlenir veya disabled açıklama metni | WP credentials Phase 13'ten yoksa import tetiklenemez |
| **idle (WP bağlı, hiç import yapılmamış)** | "WordPress Sitemi İçeri Al" primary butonu + "Henüz içerik aktarılmadı" caption | Tıklama → `startSiteImport()` server action tetiklenir |
| **idle (WP bağlı, önceki import var)** | "WordPress Sitemi Yenile" outline butonu + son import tarihi caption + "Site Analizine Git →" linki | Re-import upsert yapar — yıkıcı onay gerekmez (D-09) |
| **importing** | Buton disabled + inline progress bar + "47/120 sayfa içe aktarıldı" mesajı | SSE veya polling (500ms interval) ile güncellenir; kullanıcı sayfadan ayrılabilir |
| **importing — AI enrichment** | Progress bar dolu (100%) + "Sayfalar analiz ediliyor..." spinner caption | DB write bitti, Haiku batch çağrısı sürüyor |
| **complete** | Yeşil banner "İçe aktarma tamamlandı" + "Site Analizine Git →" primary butonu | Banner 5 saniye sonra otomatik kapanır; buton kalıcı |
| **error** | Kırmızı `text-xs text-destructive` hata satırı + "Tekrar Dene" outline butonu | WP API erişim hatası veya timeout |

### AuditFlagChips — Filtre Toggle

| Durum | Görsel | Davranış |
|-------|--------|---------|
| Tüm pasif (varsayılan) | 6 chip gri renkte — tüm sayfalar gösterilir | Filtre yok |
| Bir chip aktif | Aktif chip mavi (`bg-blue-500/20 text-blue-400 border-blue-500/30`), geri kalan gri | Yalnızca ilgili flag taşıyan satırlar listelenir |
| Birden fazla chip aktif | Aktif chip'ler mavi — OR mantığı (herhangi birini taşıyan sayfalar gösterilir) | State: `Set<string>` — toggle ile ekle/çıkar |
| Sonuç 0 | Tree alanı boş, "Bu filtrelere uyan sayfa bulunamadı" empty state metni | Filtreler sıfırla linki gösterilir |

**Chip listesi (sırayla, sol → sağ):** Orphan | Weak | Outdated | Missing Meta | Missing Keyword | Duplicate Intent

**Pattern referansı:** izleme/period-tab-bar.tsx — `cn('px-4 py-2 rounded-md text-sm', isActive ? 'bg-secondary text-foreground font-medium' : 'text-muted-foreground hover:text-foreground')` — ANCAK aktif chip için `bg-blue-500/20 text-blue-400` rengi kullanılır (period tab'ın `bg-secondary`'si değil, spesifik mavi).

### ImportedPageRow — Tree Satırı

| Durum | Görsel | Davranış |
|-------|--------|---------|
| Normal | Başlık + URL + flag badge'leri + GSC tıklama + GSC pozisyon | — |
| AI enrichment bekleniyor | `primary_intent` alanı — "Analiz ediliyor..." küçük badge | Polling veya SWR ile güncellenir; tamamlanınca intent chip gösterilir |
| GSC eşleşmesi yok | Tıklama ve pozisyon alanı `—` | `text-muted-foreground` ile gösterilir |
| Tüm flag'ler temiz | Badge alanı boş — satır "sağlıklı" | Flag yoksa badge render edilmez |
| Parent satır (child'ları var) | Child indicator yok (parent düz gösterilir); child'lar `↳` işareti ile indent altında | `depth = 0` → indent none; `depth >= 1` → `↳` prefix + `paddingLeft: 16 + depth*20` px |

### SiteAnaliziPage — Genel Sayfa Durumları

| Durum | Görsel |
|-------|--------|
| Import hiç yapılmamış | Büyük empty state — merkezi mesaj + "WordPress Sitemi İçeri Al" primary butonu |
| Import sürüyor (kullanıcı sayfaya geçti) | Progress bar + mesaj; tree alanı skeleton veya "İçe aktarma devam ediyor..." |
| Import tamamlandı, liste dolu | AuditFlagChips + tree listeleme |
| Tüm sayfalar sağlıklı (hiç flag yok) | Tree listelenir, chip alanı gösterilir; filtreleme yapıldığında "Bu filtreye uyan sayfa yok" |

## Layout Patterns

### Site Analizi Sayfa Yapısı

`/projeler/[id]/site-analizi` — izleme/page.tsx ile birebir aynı page-level container:

```
<div className="flex flex-col h-screen">
  <div className="p-8 pb-4">
    breadcrumb + "Site Analizi" başlık
  </div>
  <div className="flex flex-1 min-h-0">
    <div className="w-64 shrink-0 border-r border-border overflow-y-auto p-4">
      <ProjectNav ... />
    </div>
    <div className="flex-1 min-w-0 overflow-y-auto p-8">
      <AuditFlagChips />        ← sticky top veya sayfanın üstünde
      <ImportedPagesTree />     ← tree list (flattenTree + depth indent)
    </div>
  </div>
</div>
```

**ImportedPagesTree grid kolonları:**
```
grid grid-cols-[1fr_1fr_auto_auto_auto_auto]
```
Sütun sırası: Sayfa Başlığı | URL | Audit Flag Badge'leri | GSC Tıklama | Ort. Pozisyon | (boş — ileride aksiyon alanı)

**Tree row iç yapısı:**

```
<div style={{ paddingLeft: `${16 + page.depth * 20}px` }}>
  {page.depth > 0 && <span className="text-muted-foreground mr-1.5">↳</span>}
  <span className="text-sm">{page.title}</span>
  <span className="text-xs text-muted-foreground truncate">{page.slug}</span>
  {/* flag badge'leri */}
  {page.flag_orphan && <AuditFlagBadge flag="orphan" />}
  ...
  {/* GSC metrikleri */}
  <span className="text-xs">{page.gsc_clicks ?? '—'}</span>
  <span className="text-xs">{page.gsc_avg_position ? page.gsc_avg_position.toFixed(1) : '—'}</span>
</div>
```

### Import Bölümü — Proje Detay Sayfası

`/projeler/[id]/page.tsx` içinde `GscConnectionSection`'ın altına:

```
proje detay sayfası (page.tsx)
├── Proje bilgileri
├── WordPress Bağlantısı (WordPressConnectionSection)
├── ─── <Separator /> ───
├── Google Search Console Bağlantısı (GscConnectionSection)
├── ─── <Separator /> ───
└── WordPress Site Import (SiteImportSection)   ← YENİ
```

**SiteImportSection iç düzeni (`space-y-4` container):**
1. Başlık satırı: `flex items-center gap-3` → `<h2 text-base font-semibold>` "WordPress Sitemi İçeri Al" + durum badge
2. Açıklama metni: `text-sm text-muted-foreground` — "WordPress sitenizin mevcut içeriğini okuyarak analiz için hazırlar."
3. Import progress alanı (importing durumunda): progress bar + "47/120 sayfa içe aktarıldı" caption
4. Tamamlama banner (complete durumunda): yeşil satır + "Site Analizine Git →" link butonu
5. Hata metni (error durumunda): `text-xs text-destructive`
6. CTA buton: `flex justify-end` → "WordPress Sitemi İçeri Al" veya "WordPress Sitemi Yenile"

### AuditFlagChips Yerleşimi

Tree alanının hemen üstünde, sayfanın content alanında `mb-4` boşluk ile:

```
<div className="inline-flex items-center gap-1 bg-card border border-border rounded-lg p-1 mb-4 flex-wrap">
  {chips.map(chip => (
    <button className={cn('px-4 py-2 rounded-md text-sm', isActive ? 'bg-blue-500/20 text-blue-400 font-medium' : 'text-muted-foreground hover:text-foreground')}>
      {chip.label}
    </button>
  ))}
</div>
```

## Accessibility Contract

- Tüm butonlar açık metin içerir (`aria-label` gerektiğinde eklenir — ikonlu butonlarda)
- Progress bar: `<progress value={current} max={total} aria-label="İçe aktarma ilerleme durumu" />` veya `role="progressbar" aria-valuenow aria-valuemax` ile custom div
- AuditFlagChips: Her chip butonu `aria-pressed={isActive}` — toggle durumu ekran okuyuculara iletilir
- Import tamamlama banner: `aria-live="polite"` ile dinamik içerik değişimi bildirilir
- Tree satırları: `role="list"` + `role="listitem"` ile semantik yapı; iç içe depth için `aria-level` attribute
- Disabled butonlarda `title` attribute ile açıklama sağlanır
- GSC değeri `—` gösterildiğinde: `aria-label="GSC verisi yok"` ile screen reader uyumluluğu
- Hata mesajları `role="alert"` ile işaretlenir
