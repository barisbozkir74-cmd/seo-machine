## What Was Built

### src/lib/wp/url-normalize.ts

`normalizeUrl(url: string): string` pure fonksiyonu:
- `https://www.example.com/page/` → `https://example.com/page`
- `http://example.com/page` → `https://example.com/page`
- `https://example.com/page?q=1#section` → `https://example.com/page`
- `https://example.com/` → `https://example.com`
- Parse hatası → input değiştirilmeden döner

Native `URL` API kullanılıyor (regex chain değil — RESEARCH.md "Don't Hand-Roll").

### src/lib/wp/normalize.ts

- `ImportedPage` interface: DB kolonlarıyla birebir eşleşme + `yoast_title` / `yoast_description` (test beklentisi)
- `ImportedPageWithDepth` interface: `depth: number` eklenmiş
- `normalizeWpPage(item, projectId, wpType)`: WP REST API raw item → ImportedPage
  - HTML entity decode (&#8220; gibi entity'ler)
  - WP `parent=0` → `parent_wp_id=null`
  - Yoast metadata optional chain ile güvenli okuma
- `flattenImportedTree(pages)`: parent/child ilişkisini `__root__` key ile çözer, depth artar

### src/lib/wp/import.ts

- `fetchAllWpContent(wpUrl, authHeader, endpoint)`: WP REST API pagination loop
  - `X-WP-TotalPages` header ile totalPages belirlenir
  - `per_page=100` ile her sayfa çekilir
  - `_fields=id,title,link,slug,parent,date,modified,status,menu_order,yoast_head_json,excerpt` — Pitfall 2 guard
  - `AbortSignal.timeout(30_000)` — T-15.5-03-02 DoS mitigation
  - `fetchWithRetry` ile 429 → Retry-After bekleme
  - 50ms batch delay (son sayfa hariç)
  - `authHeader` asla loglanmaz — T-15.5-03-01
