### Task 2: SiteImportSection bileşeni

`src/app/(dashboard)/projeler/[id]/site-import-section.tsx` — 252 satır, `'use client'`

**State machine:**

| Status | Tetikleyici | Görsel |
|--------|-------------|--------|
| `idle` (WP yok) | `hasWpCredentials=false` | Disabled açıklama metni |
| `idle` (hiç import yok) | `initialImportStatus=null` | "WordPress Sitemi İçeri Al" primary butonu |
| `idle` (önceki import var) | `importCompletedAt != null` | "WordPress Sitemi Yenile" outline + son tarih + "Site Analizine Git →" |
| `running` | `startSiteImport()` tetiklendi | Progress bar + "N/T sayfa içe aktarıldı" |
| `enriching` | Polling `status=enriching` döndü | Progress bar 100% + "Sayfalar analiz ediliyor..." |
| `complete` | Polling `status=complete` döndü | Yeşil `aria-live="polite"` banner + "Site Analizine Git →" |
| `error` | Polling `status=error` veya fetch hatası | `role="alert"` hata metni + "Tekrar Dene" outline |

**Polling (D-07):**
- 500ms `setInterval` — sadece `running` veya `enriching` durumunda aktif
- `complete` veya `error` gelince `clearInterval` — gereksiz istek yok
- `useEffect` cleanup ile component unmount'ta interval temizlenir

**Erişilebilirlik (UI-SPEC Accessibility Contract):**
- `aria-live="polite"` — tamamlama banner
- `role="progressbar" aria-valuenow aria-valuemax aria-label` — progress div
- `role="alert"` — hata metni
- `role="status"` — tamamlama banner wrapper

**Tüm metinler Türkçe** — UI-SPEC Copywriting Contract'tan alındı.
