# Phase 8 — UI Design Contract: Page Planner & Internal Links

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | shadcn/ui | components.json |
| Preset | base-mira | components.json |
| Component library | @base-ui/react | STATE.md decisions |
| Icon library | hugeicons (free tier) | components.json iconLibrary |
| Font | System default (Geist Sans — inherited from Phase 1 globals.css) | globals.css |
| Theme | Dark mode enforced statically — `html className="dark"` | STATE.md decisions |

**Critical patterns (locked across all phases — must not deviate):**
- `DialogTrigger` uses `render` prop — NOT `asChild` — because `@base-ui/react` does not support `asChild`
- `Badge` / inline badges use direct `className` color classes — NO `variant` prop
- Font weight: `font-normal` (400) or `font-semibold` (600) ONLY — `font-medium` is FORBIDDEN
- Tailwind v4 CSS-first: all theme via CSS custom properties in `globals.css`, no `tailwind.config.ts`
- Native HTML `<select>` for dropdowns: `className="w-full h-9 rounded-md border border-input bg-background px-3 py-1 text-sm"` (established pattern from AddPageDialog)
- `PriorityBadge` and link-type badges use `inline-flex rounded-full px-2 py-0.5 text-xs` with direct color classes (established in sayfalar/page.tsx)

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding (`px-1.5 py-0.5`), checkbox gap |
| sm | 8px | Compact element spacing, button gaps (`gap-2`) |
| md | 16px | Default cell padding (`px-4`), form field spacing, dialog row padding |
| lg | 24px | Section padding, dialog content spacing (`p-6`) |
| xl | 32px | Page-level padding (`p-8` — established pattern) |
| 2xl | 48px | Section vertical breaks (`space-y-8` in right content area) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Dialog max-height: `max-h-[70vh]` with `overflow-y-auto` — exact vh value, not on pixel scale (per D-01 resolution)
- Orphan banner: `px-4 py-3` = 16px/12px — py is 12px (not on scale), preserved from established amber warning pattern in Phase 7

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 | Table cell text, dialog body, select labels, descriptions |
| Label | 12px (`text-xs`) | 400 (`font-normal`) | 1.4 | Table headers, badge text, muted annotations, anchor text hints |
| Heading | 16px (`text-base`) | 600 (`font-semibold`) | 1.2 | Section headings (`h2`), dialog titles |
| Display | 20px (`text-xl`) | 600 (`font-semibold`) | 1.2 | Page titles (`h1`) — "Sayfa Listesi", "İç Link Haritası" |

**Note:** `font-medium` is never used. Where the existing `sayfalar/page.tsx` uses `font-medium` on TableCell (line 229), Phase 8 must NOT replicate this — use `font-normal` or `font-semibold` only.

## Color

Dark mode values (active via `html className="dark"`):

| Role | CSS Custom Property | Dark Value | Usage |
|------|---------------------|------------|-------|
| Dominant (60%) | `--background` | `#020817` (Slate 950) | Page background, table row backgrounds, dialog body |
| Secondary (30%) | `--card` / `--secondary` | `#0f172a` / `#1e293b` (Slate 900/800) | Table headers (`bg-secondary/40`), hover states (`hover:bg-muted/30`), dialog backgrounds |
| Accent (10%) | `--primary` | `#f8fafc` (Slate 50) | Primary submit buttons only: "Kaydet" in BulkEditPagesDialog, "Seçilenleri Ekle" in SuggestLinksDialog |
| Destructive | `--destructive` | `#ef4444` (Red 500) | Delete button hover states only |
| Amber semantic | `text-amber-400` / `bg-amber-500/20` / `border-amber-500/30` | Amber | Orphan detection banner, "Tip Atanmamış" inline warning badge in SuggestLinksDialog |

Accent reserved for:
- "Kaydet" primary button in BulkEditPagesDialog footer ONLY

Semantic colors by element:

## Component Inventory

### 1. "Toplu Düzenle" Button — sayfalar/page.tsx header

**Location:** `sayfalar/page.tsx` — header `div.flex.items-center.justify-between`, sibling of `AddPageDialog`

**Before (existing):**
```
[Sayfa Listesi h1]  [domain subtitle]    [Sayfa Ekle button]
```

**After Phase 8:**
```
[Sayfa Listesi h1]  [domain subtitle]    [Toplu Düzenle button]  [Sayfa Ekle button]
```

- "Toplu Düzenle": `variant="outline" size="sm"` — opens BulkEditPagesDialog
- Disabled state when `pages.length === 0`: `disabled` prop + native `title="Düzenlenecek sayfa yok"` attribute on wrapping `<span>`
- No loading state on the trigger button itself — loading is handled inside the dialog's "Kaydet" button

### 2. BulkEditPagesDialog — Client Component

**File:** `sayfalar/BulkEditPagesDialog.tsx`

**Trigger pattern:** `DialogTrigger render={<Button variant="outline" size="sm">Toplu Düzenle</Button>}` — render prop (NOT asChild)

**Dialog dimensions:** `max-w-2xl`

**Header:** `DialogTitle` — "Toplu Sayfa Düzenleme"

**Subheader copy:** `<p className="text-sm text-muted-foreground">Sayfa özelliklerini toplu olarak düzenleyin.</p>`

**Scrollable table container:** `max-h-[70vh] overflow-y-auto` wrapping the table

**Table — 4 columns:**

| Column | Width | Content | Interaction |
|--------|-------|---------|-------------|
| Sayfa Adı | flex-1 | Page title — read-only `text-sm font-normal` | None |
| Tip | `w-40` | Native `<select>` with `PAGE_TYPE_LABELS` options | Editable per row |
| Focus Keyword | `w-48` | Native `<select>` — project keyword list, ordered by keyword text | Editable per row; shows `—` option as first item (value: `""`) |
| Öncelik | `w-32` | Native `<select>` — options: `yüksek`, `orta`, `düşük` | Editable per row |

**Table header row:** `bg-secondary/40 border-b border-border text-xs text-muted-foreground font-normal`

**Table body rows:** `border-b border-border last:border-0 hover:bg-muted/30 transition-colors`

**Select element class (all three selects):** `w-full h-8 rounded-md border border-input bg-background px-2 py-0 text-sm text-foreground`

**Dirty state tracking:** Client state — `Map<pageId, Partial<PageAttributeUpdate>>`. Only changed rows are sent to the server action. Unchanged rows are not included in the payload.

**Footer:**
- Left: dirty count summary — `"{N} satır değiştirildi"` (`text-sm text-muted-foreground`) — shows `"Değişiklik yok"` when 0 dirty rows
- Right: `[İptal]` ghost variant + `[Kaydet]` primary variant

**"Kaydet" button states:**
- Default (0 dirty rows): `disabled` prop, primary fill but `opacity-50 cursor-not-allowed`
- Default (1+ dirty rows): primary fill, text "Kaydet"
- Loading: `opacity-50 cursor-wait`, text "Kaydediliyor…"
- Success: dialog closes, page re-renders via `router.refresh()`

**Error state (inline, footer left):** `<p className="text-sm text-destructive">Kaydetme başarısız. Lütfen tekrar deneyin.</p>` — replaces dirty count

**Empty state (0 pages):** Dialog does not open — trigger button is `disabled`. If dialog somehow renders with empty list: `<p className="text-sm text-muted-foreground py-12 text-center">Düzenlenecek sayfa bulunamadı.</p>`

### 3. "Öner" Button (SuggestLinksButton) — ic-link-haritasi/page.tsx header

**File:** `ic-link-haritasi/SuggestLinksButton.tsx` (Client Component)

**Location:** `ic-link-haritasi/page.tsx` — header `div.flex.items-center.justify-between`, sibling of `AddLinkDialog`

**Before (existing):**
```
[Linkler h2]                             [Link Ekle button]
```

**After Phase 8:**
```
[Linkler h2]                  [Öner button]  [Link Ekle button]
```

- "Öner": `variant="outline" size="sm"` — calls `suggestInternalLinks` server action, then opens `SuggestLinksDialog` with returned suggestions
- Disabled when `pages.length === 0`: native `title="Önce sayfa oluşturun"` on wrapper `<span>`
- Loading state: `useTransition` — button text "Yükleniyor…", `opacity-50 cursor-wait`
- If `suggestInternalLinks` returns empty array: display inline toast/text `"Önerilecek yeni link bulunamadı."` — no dialog opens

### 4. SuggestLinksDialog — Client Component

**File:** `ic-link-haritasi/SuggestLinksDialog.tsx`

**Opens:** After `SuggestLinksButton` resolves with 1+ suggestions

**Dialog dimensions:** `max-w-2xl`

**Header:** `DialogTitle` — "İç Link Önerileri"

**Subheader copy:** `<p className="text-sm text-muted-foreground">Sistem, pillar–destek ilişkisine göre link önerileri oluşturdu. Onaylamak istediklerinizi seçin.</p>`

**Scrollable table container:** `max-h-[70vh] overflow-y-auto`

**Table — 5 columns:**

| Column | Width | Content | Interaction |
|--------|-------|---------|-------------|
| (checkbox) | `w-8` | `<input type="checkbox">` — per row selection | Toggle include/exclude |
| Kaynak Sayfa | flex-1 | Source page title, `text-sm font-normal` | Read-only |
| Hedef Sayfa | flex-1 | Target page title, `text-sm font-normal` | Read-only |
| Anchor Text | flex-1 | Suggested anchor text, `text-sm text-muted-foreground` | Read-only |
| Link Tipi | `w-32` | Native `<select>` — contextual / navigation / footer / breadcrumb | Editable per row; default `contextual` |

**"Tip Atanmamış" warning badge (D-04 edge case):**
When a suggestion row has `page_type === null` on either the source or target page:
```tsx
<span className="ml-2 text-xs px-1.5 py-0.5 rounded bg-amber-500/20 text-amber-400 border border-amber-500/30">
  Tip Atanmamış
</span>
```
Displayed inline after the page title in the Kaynak Sayfa cell. These rows can still be selected but carry a visual warning.

**Select-all row:** Header row has a master checkbox — checks/unchecks all visible rows. `indeterminate` state when some but not all rows are checked.

**Table header row:** `bg-secondary/40 border-b border-border text-xs text-muted-foreground font-normal`

**Table body rows:** `border-b border-border last:border-0 hover:bg-muted/30 transition-colors`

**Footer:**
- Left: selection count — `"{N} öneri seçildi"` (`text-sm text-muted-foreground`)
- Right: `[İptal]` ghost variant + `[Seçilenleri Ekle]` primary variant

**"Seçilenleri Ekle" button states:**
- Default (0 selected): `disabled` prop, `opacity-50 cursor-not-allowed`
- Default (1+ selected): primary fill, text "Seçilenleri Ekle"
- Loading: `opacity-50 cursor-wait`, text "Ekleniyor…"
- Success: dialog closes, page re-renders via `router.refresh()`. Bulk `addLink` is called sequentially for each selected row (existing `addLink` Server Action).

**Error state (inline, footer left):** `<p className="text-sm text-destructive">Link eklenemedi. Lütfen tekrar deneyin.</p>`

### 5. Orphan Detection Banner — ic-link-haritasi/page.tsx

**Location:** `ic-link-haritasi/page.tsx` — rendered above the "Linkler" section heading when `orphanPages.length > 0`

**Computation:** SSR, pure function — `pages` minus any page that appears as `source_page_id` or `target_page_id` in `links`.

**Condition:** Only rendered when `links.length > 0 && orphanPages.length > 0`. When no links exist, the banner is suppressed (orphan state cannot be meaningfully determined).

**Markup pattern (established from Phase 7 amber warning):**
```tsx
{orphanPages.length > 0 && links.length > 0 && (
  <div className="rounded-md border border-amber-500/30 bg-amber-500/20 px-4 py-3 text-sm text-amber-400">
    <span className="font-semibold">⚠ {orphanPages.length} sayfa hiçbir linke bağlı değil: </span>
    {orphanPages.map((p, i) => (
      <span key={p.id}>
        {i > 0 && ', '}
        <span className="font-semibold">[{p.title}]</span>
      </span>
    ))}
    <span className="block mt-1 text-amber-400/70 text-xs">
      Bu sayfalara gelen veya giden link ekleyin.
    </span>
  </div>
)}
```

**Position in page layout:** Immediately above the `div.flex.items-center.justify-between` header row (above h2 "Linkler" and the button group).

**Typography in banner:**
- Main line: `text-sm text-amber-400`
- Page names: `font-semibold` inline
- Sub-line hint: `text-xs text-amber-400/70`

## Interaction States

### BulkEditPagesDialog — row and button states

| State | Visual |
|-------|--------|
| Row — unchanged | `bg-background`, selects show current DB value |
| Row — changed (dirty) | No visual diff on row itself; dirty count in footer increments |
| Kaydet — no changes | `disabled opacity-50 cursor-not-allowed` primary button |
| Kaydet — has changes | Primary fill, enabled |
| Kaydet — submitting | `opacity-50 cursor-wait`, text "Kaydediliyor…", all selects disabled |
| Kaydet — error | Button re-enables; error copy in footer left |

### SuggestLinksDialog — row and button states

| State | Visual |
|-------|--------|
| Row — unchecked | Normal bg, checkbox empty |
| Row — checked | `bg-muted/30`, checkbox checked |
| Row — "Tip Atanmamış" | Amber badge inline after page title; row still selectable |
| Master checkbox — none | Empty |
| Master checkbox — some | Indeterminate (`ref.indeterminate = true`) |
| Master checkbox — all | Checked |
| Seçilenleri Ekle — 0 selected | `disabled opacity-50 cursor-not-allowed` |
| Seçilenleri Ekle — has selection | Primary fill, enabled |
| Seçilenleri Ekle — submitting | `opacity-50 cursor-wait`, text "Ekleniyor…", all checkboxes and selects disabled |

### SuggestLinksButton

| State | Visual |
|-------|--------|
