## Spacing Scale

Tailwind v4 CSS-first config — no tailwind.config.ts. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (p-1) | Icon gaps, badge inner padding, QA badge icon-text gap |
| sm | 8px (p-2) | Compact element spacing, section header vertical padding |
| md | 16px (p-4) | Default element spacing, form field gaps, panel padding |
| lg | 24px (p-6) | Section padding, editor section gaps |
| xl | 32px (p-8) | Layout gaps, page content horizontal padding |
| 2xl | 48px (p-12) | Major section breaks |
| 3xl | 64px (p-16) | Page-level top/bottom spacing |

Exceptions:
- Locked-state banner: `py-3 px-4` (12px/16px) — compact warning, not full section
- Character counter badge inline: no extra padding, inherits text-xs sizing
- Package list item row height: `py-3` (12px vertical) for density with 3-badge layout per row

## Typography

Font: Geist Sans via `--font-sans` CSS variable, applied globally via `html { @apply font-sans }`.
Mono: Geist Mono via `--font-mono` — used exclusively for JSON textarea fields.

| Role | Size | Weight | Line Height | Tailwind class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm font-normal leading-relaxed` |
| Label | 12px | 400 (regular) | 1.4 | `text-xs font-normal leading-snug` |
| Heading | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold leading-tight` |
| Display | 16px | 600 (semibold) | 1.3 | `text-base font-semibold leading-snug` |

Notes:
- Section headers inside PagePackageEditor use `text-sm font-semibold` (14px/600) — NOT Display role
- JSON textarea fields use `font-mono text-xs` (12px monospace)
- Character counter spans use `text-xs font-normal` — colored conditionally (see Color section)
- `font-medium` is globally prohibited — use `font-semibold` (600) or `font-normal` (400) only

1. "Kaydet" — primary save button in PagePackageEditor
2. "AI ile Üret" — AI generation trigger button
3. "Onayla" — status transition: draft → approved
4. "Kilitle" — status transition: approved → locked

All other buttons use `variant="outline"` or `variant="ghost"`.

### Page List Panel (orta panel — w-72)

Each page row displays:
- Page title (`text-sm font-normal leading-tight text-foreground/80`)
- Page type chip (`text-xs text-muted-foreground`)
- Package status badge (PackageStatusBadge)
- If no package exists: inline "Üret" (outline, xs) and "Manuel Başlat" (ghost, xs) buttons

Active row: `bg-secondary border-l-2 border-l-foreground`
Inactive row: `border-l-2 border-l-transparent hover:bg-secondary/50 hover:border-l-border`

### Package Editor Header (sağ panel üstü)

```
┌──────────────────────────────────────────────────────┐
│  [Sayfa başlığı text-base font-semibold]             │
│  [Focus keyword: <kw> text-sm text-muted-foreground] │
│                                                      │
│  [QaBadge] [PackageStatusBadge]    [Action buttons]  │
└──────────────────────────────────────────────────────┘
```

Action buttons by status:
- `draft`: "Onayla" (primary) + "AI ile Üret" (outline)
- `approved`: "Kilitle" (primary) + "AI ile Üret" (outline) + "Taslağa Al" (ghost)
- `locked`: "Kilidini Aç" (outline, triggers confirmation dialog)
- No package: "AI ile Üret" (primary) + "Manuel Başlat" (outline)

### Locked State

When `status === 'locked'`:
- LockedBanner renders directly below editor header: amber-tinted full-width bar
- All Input, Textarea fields get `disabled` prop
- Save button is hidden
- "Kilidini Aç" button is visible (outline style, not destructive color — it's reversible)

## Interaction Contracts

### AI Generation Flow

1. User clicks "AI ile Üret"
2. Button shows spinner + "Üretiliyor..." label, disabled
3. Streaming response reads until done
4. `applyAiFields()` populates form state
5. Status auto-sets to `draft` (if no existing package, a `page_packages` row is created)
6. Button returns to idle; success message: "Alanlar dolduruldu — kaydetmeyi unutma."
7. Error state: inline red text below button showing error message

### Manual Start Flow

1. User clicks "Manuel Başlat" (from list panel — no package exists)
2. Empty `page_packages` row created with `status: 'draft'`, `generated_by: 'manual'`
3. Editor panel loads with all empty fields, no AI pre-fill
4. Form is editable immediately

### QA Validator (real-time, client-side only)

Computed on every keystroke from form state. No server call.

| Rule ID | Check | Severity |
|---------|-------|----------|
| QA-01 | `seo_title.length <= 60` | warning if >60, error if >70 |
| QA-02 | `meta_description.length <= 155` | warning if >155, error if >170 |
| QA-03 | `h1.trim().length > 0` | error if empty |
| QA-04 | `seo_title.toLowerCase().includes(focusKeyword.toLowerCase())` | warning if missing |

QaBadge displays:
- All pass: `✓ QA Geçti` — `text-emerald-400`
- Has warnings, no errors: `⚠ N Uyarı` — `text-amber-400`
- Has errors: `✕ Hata` — `text-red-400`

Character counter (inline in Field component):
- `≤ maxLen`: `text-muted-foreground` (counts chars silently)
- `> maxLen (warning threshold)`: `text-amber-400`
- `> hard limit (error threshold)`: `text-red-400`

### Status Transitions

| From | Action | To | Confirmation? |
|------|--------|----|---------------|
| — (no package) | AI ile Üret / Manuel Başlat | draft | No |
| draft | Onayla | approved | No |
| approved | Kilitle | locked | No |
| locked | Kilidini Aç | approved | Yes — inline Dialog |
| approved | Taslağa Al | draft | No |

"Kilidini Aç" confirmation dialog copy:
- Title: "Paketi kilidden çıkar"
- Body: "Bu sayfa paketi kilitli. Kilidini açarsan düzenlenebilir hale gelir ve onay durumuna döner."
- Confirm button: "Kilidini Aç" (outline)
- Cancel button: "İptal" (ghost)

Dialog uses `DialogTrigger render={}` pattern (NOT asChild).

### Save Flow

1. User clicks "Kaydet"
2. Button shows "Kaydediliyor..." + disabled
3. `updatePagePackage` server action writes to `page_packages`
4. On success: `router.refresh()` + inline "Kaydedildi." emerald message
5. On error: inline red message with `result.error` text
