## Spacing Scale

Declared values (multiples of 4, consistent with existing codebase):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap (HugeiconsIcon size={16} ile birlikte), badge padding |
| sm | 8px | Button gap, inline element spacing |
| md | 16px | Default section spacing (`space-y-4`) |
| lg | 24px | Major element separation (`space-y-6`) |
| xl | 32px | Section breaks |
| 2xl | 48px | — |
| 3xl | 64px | — |

**Exceptions:**
- Touch target minimum: 44px yükseklik (`min-h-[44px]`) — OAuth bağlantı butonu ve primary CTA butonları. WordPressConnectionSection'daki mevcut pattern ile tutarlı.
- Badge padding: `px-1.5 py-0.5` (6px / 2px) — GscIndexBadge için RESEARCH.md Pattern 6'dan alınmış.
- Input yüksekliği: `h-9` (36px) — mevcut WordPressConnectionSection pattern ile tutarlı.

## Interaction States

### GscConnectionSection Durumları

| Durum | Görsel | Davranış |
|-------|--------|---------|
| Bağlı değil | Badge: gri "Yapılandırılmadı" + "GSC Bağla" butonu | Tıklama → `initiateGscOAuth()` server action → Google consent screen |
| OAuth yükleniyor | Buton disabled + "Bağlanıyor..." text | Redirect beklenirken — Next.js `redirect()` ile anında tetiklenir |
| Bağlı, property seçilmedi | Badge: yeşil "Bağlı" + property Select dropdown açık | Sites.list sonuçları Select options olarak gösterilir |
| Property seçildi, kaydedilmedi | "Kaydet" butonu aktif | Kullanıcı seçim yaptı ama henüz kaydetmedi |
| Kaydediliyor | "Kaydet" butonu disabled + "Kaydediliyor..." | `saveGscProperty()` server action sürüyor |
| Tam yapılandırılmış | Badge: yeşil "Bağlı" + seçili property URL gösterilir + "Senkronize Et" butonu | Aktif durum |
| OAuth hatası (CSRF/iptal) | Hata mesajı banner (`text-xs text-destructive`) | URL'den `?error=gsc_denied` veya `?error=gsc_csrf` okunur |

### GscIndexBadge Durumları

| `gsc_index_status` | Badge Metni | Renk |
|-------------------|-------------|------|
| `null` (kontrol edilmedi) | Badge gösterilmez | — |
| `'indexed'` | İndekslendi | `bg-emerald-900/40 text-emerald-400` |
| `'not_indexed'` | İndekslenmedi | `bg-red-900/40 text-red-400` |
| `'crawled_not_indexed'` | Tarandı/İndekslenmedi | `bg-amber-900/40 text-amber-400` |

### "Index Durumunu Kontrol Et" Butonu (HtmlReadyBanner)

| Durum | Görsel | Davranış |
|-------|--------|---------|
| GSC bağlı değil | Buton gizlenir veya disabled + tooltip | GSC property seçilmemişse kontrol yapılamaz |
| Hazır | "Index Durumunu Kontrol Et" — `variant="outline"` | Tıklama → `checkIndexStatus()` server action |
| Kontrol ediliyor | Buton disabled + "Kontrol Ediliyor..." | Server action sürüyor |
| Tamamlandı | GscIndexBadge güncellendi + son kontrol tarihi gösterilir | `gsc_index_checked_at` formatlanarak gösterilir |
| API hatası | `text-xs text-destructive` hata mesajı | "Index durumu alınamadı. Tekrar deneyin." |

### "Senkronize Et" Butonu

| Durum | Görsel | Davranış |
|-------|--------|---------|
| Hazır | "Senkronize Et" — `variant="outline" size="sm"` | POST /api/gsc/sync tetikler |
| Senkronize ediliyor | Buton disabled + "Senkronize Ediliyor..." | n8n webhook yanıt beklenirken |
| Başarılı | "Son senkronizasyon: [tarih]" caption güncellenir | `text-xs text-muted-foreground` |
| Hata | `text-xs text-destructive` | "Senkronizasyon başarısız. Tekrar deneyin." |

## Layout Patterns

### GscConnectionSection Yerleşimi

`/projeler/[id]` sayfasında WordPress bölümünün (`WordPressConnectionSection`) hemen altına eklenir. Tam yapı:

```
proje detay sayfası (page.tsx)
├── Proje bilgileri bölümü
├── WordPress Bağlantısı (WordPressConnectionSection) — mevcut
├── ─── <Separator /> ───
├── Google Search Console Bağlantısı (GscConnectionSection) — YENİ
└── ...
```

İç düzen (`space-y-4` container):
1. Başlık satırı: `flex items-center gap-3` → `<h2 text-base font-semibold>` + durum badge
2. Property dropdown (bağlıysa): `<Select>` — Sites.list sonuçları
3. "Senkronize Et" butonu + son sync tarihi (property seçiliyse)
4. Hata mesajı (varsa): `text-xs text-destructive`
5. CTA buton alanı: `flex justify-end` → "GSC Bağla" veya "Kaydet"

### GscIndexBadge Yerleşimi

- **Sayfa paketi listesi:** WP publish badge'lerinin yanına inline eklenir — `flex items-center gap-1.5` içinde
- **HtmlReadyBanner / İçerik Studio:** "Index Durumunu Kontrol Et" butonu ve badge yan yana — `flex items-center gap-2` içinde, banner'ın action alanına yerleştirilir

## Accessibility Contract

- Tüm butonlar `aria-label` veya açık metin içerir
- Badge'ler `aria-live="polite"` ile durum değişimlerini okuyuculara bildirir (WordPressConnectionSection pattern'ı izlenir)
- Property `<Select>` bileşeni Radix Select — klavye navigasyonu ve screen reader uyumluluğu sağlanmış
- Disabled butonlarda `title` attribute ile ipucu (tooltip) sağlanır
- Form input'larında `htmlFor` / `id` eşleşmesi zorunludur
- Hata mesajları `role="alert"` veya `aria-describedby` ile ilgili input'a bağlanır
