# Phase 7 — UI Design Contract: Site Blueprint & Tree

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | shadcn/ui | components.json |
| Preset | base-mira | components.json |
| Component library | @base-ui/react | STATE.md decisions |
| Icon library | hugeicons (free tier) | components.json iconLibrary |
| Font | System default (inherited from Phase 1) | existing pages |
| Theme | Dark mode enforced statically — `html className="dark"` | STATE.md decisions |

**Critical patterns (from STATE.md and existing code):**
- `DialogTrigger` uses `render` prop — NOT `asChild` — because `@base-ui/react` does not support `asChild`
- `Badge` uses direct `className` color classes — NO `variant` prop
- Font weight: `font-normal` (400) or `font-semibold` (600) ONLY — `font-medium` is forbidden
- Tailwind v4 CSS-first: all theme via CSS custom properties in `globals.css`, no `tailwind.config.ts`
- `select` elements: native HTML `<select>` with class `w-full h-9 rounded-md border border-input bg-background px-3 py-1 text-sm` (established in AddPageModal)

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline spacing |
| sm | 8px | Compact element spacing, button gaps |
| md | 16px | Default cell padding, form field spacing |
| lg | 24px | Section padding, dialog content spacing |
| xl | 32px | Page-level padding (`p-8` = 32px, established pattern) |
| 2xl | 48px | Section vertical breaks (`space-y-12` established in site-blueprint) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Tree row depth indent: `paddingLeft = 16 + depth * 20px` — inherited from existing `flattenTree` display (not on scale, preserved for continuity)
- Reorder button group width: 40px (two 20px icon buttons side by side, fits `w-10` column)
- Touch/click targets for ↑↓ buttons: minimum 28px height (`h-7`) matching existing ghost button pattern

## Color

Dark mode values (active via `html className="dark"`):

| Role | CSS Custom Property | Dark Value | Usage |
|------|---------------------|------------|-------|
| Dominant (60%) | `--background` | `#020817` (Slate 950) | Page background, table row backgrounds |
| Secondary (30%) | `--card` / `--secondary` | `#0f172a` / `#1e293b` (Slate 900/800) | Table headers (`bg-muted/50`), hover states (`hover:bg-muted/30`), dialog backgrounds |
| Accent (10%) | `--primary` | `#f8fafc` (Slate 50) | Submit buttons only ("Oluştur", "Kaydet" primary actions) |
| Destructive | `--destructive` | `#ef4444` (Red 500) | Delete button hover, error messages, conflict badge background |
| Amber semantic | `text-amber-400` / `bg-amber-500/10` | Amber 400 / Amber 500 10% | "Zaten var" badge, unmapped keyword warning cards, enrichment warnings |
| Muted text | `--muted-foreground` | `#64748b` (Slate 500) | Slugs, secondary data, disabled states, table sub-labels |

Accent reserved for:
- Primary submit button fill ONLY: "Oluştur" in GeneratePagesDialog, "Ekle" in AddPageModal
- NOT used for: tab active state, badges, reorder buttons, toggle links

Semantic colors by intent:
- `text-red-500` / `bg-red-500/20` — "⚠ Çakışma" conflict badge (BLUE-02)
- `text-amber-400` / `bg-amber-500/10` — "Zaten var" skip badge, "Eşleşmeyenler" warning section
- `text-muted-foreground` — depth indicators (↳), slugs, focus keyword column

### 2. Tab Switcher — Ağaç / Keyword Eşleme

**Pattern:** Same as Phase 6 `ViewToggle` — searchParams-based, no client state

**Tabs:**
- Tab 1: "Ağaç Görünümü" — `?tab=tree` (default when param absent)
- Tab 2: "Keyword Eşleme" — `?tab=mapping`

**Markup pattern (established from ViewToggle + keyword-stratejisi):**
```tsx
<div className="flex items-center gap-1 border border-border rounded-md p-0.5">
  <Link
    href={`?tab=tree`}
    className={cn(
      'px-3 py-1.5 rounded text-sm transition-colors',
      tab === 'tree' || !tab
        ? 'bg-secondary text-foreground font-semibold'
        : 'text-muted-foreground hover:text-foreground font-normal'
    )}
  >
    Ağaç Görünümü
  </Link>
  <Link
    href={`?tab=mapping`}
    className={cn(
      'px-3 py-1.5 rounded text-sm transition-colors',
      tab === 'mapping'
        ? 'bg-secondary text-foreground font-semibold'
        : 'text-muted-foreground hover:text-foreground font-normal'
    )}
  >
    Keyword Eşleme
  </Link>
</div>
```

Active tab: `bg-secondary` fill, `font-semibold`, `text-foreground`
Inactive tab: `font-normal`, `text-muted-foreground`, hover `text-foreground`

### 3. GeneratePagesDialog

**Trigger:** `DialogTrigger render={<Button variant="outline" size="sm" />}` — render prop pattern (NOT asChild)

**Dialog dimensions:** `max-w-2xl` (wider than standard to fit 5-column preview table)

**Header:** `DialogTitle` — "Kümelerden Sayfa Oluştur"

**Preview Table — 5 columns:**

| Column | Width | Content |
|--------|-------|---------|
| Küme Adı | flex-1 | Cluster name (read-only, `text-sm text-muted-foreground`) |
| Sayfa Adı | flex-1 | Editable `<input>` — plain text, `text-sm`, `border-b border-border bg-transparent` style |
| Tip | w-36 | Native `<select>` with `PAGE_TYPE_LABELS` options, `text-sm` |
| Odak Keyword | w-40 | Primary keyword text (read-only, `text-xs text-muted-foreground font-mono`) |
| Dahil Et | w-12 | Checkbox — checked = include, unchecked = skip |

**"Zaten var" rows:**
- Row background: `bg-amber-500/10`
- Checkbox: pre-checked OFF (skip by default)
- Badge in Sayfa Adı cell: `<span className="ml-2 text-xs px-1.5 py-0.5 rounded bg-amber-500/20 text-amber-400">Zaten var</span>`
- Editable input in these rows: disabled, `opacity-50 cursor-not-allowed`

**Table header row:** `bg-muted/50 border-b border-border text-xs text-muted-foreground font-normal`

**Footer:**
- Left: count summary — `"{N} sayfa oluşturulacak"` (`text-sm text-muted-foreground`)
- Right: `[İptal]` ghost + `[Oluştur]` primary

**"Oluştur" button states:**
- Default: primary fill, text "Oluştur"
- Loading: `opacity-50 cursor-wait`, text "Oluşturuluyor…"
- Disabled (0 included rows): `disabled` prop

**Empty state (0 enriched clusters):** Dialog does not open — button disabled with tooltip. If dialog somehow opens with empty list, show centered: `<p className="text-sm text-muted-foreground py-8 text-center">Kümelenmiş keyword bulunamadı. Önce keyword stratejisi sayfasından kümeleme yapın.</p>`

### 4. Tree Table — Reorder ↑↓ Arrows

**Location:** Each row in the existing `flatPages.map()` — right-side action column

**Column layout change:** Grid updates from `grid-cols-[1fr_1fr_auto_auto_auto]` to `grid-cols-[1fr_1fr_auto_auto_auto_auto]` — adds reorder column before delete column.

**Reorder column width:** `w-16` — houses two icon buttons side by side

**Visibility:** Always visible (not hover-only — avoids accidental trigger confusion on hover)

**Markup:**
```tsx
<div className="px-2 py-2 w-16 flex items-center gap-0.5">
  <ReorderButton pageId={page.id} direction="up" projectId={id} isFirst={index === 0} />
  <ReorderButton pageId={page.id} direction="down" projectId={id} isLast={index === flatPages.length - 1} />
</div>
```

**ReorderButton:**
- `variant="ghost" size="sm"` — `h-7 w-7 p-0`
- Up arrow: `↑` text or ChevronUp icon from hugeicons
- Down arrow: `↓` text or ChevronDown icon from hugeicons
- `text-muted-foreground hover:text-foreground`
- First row: up button `disabled opacity-30`
- Last row: down button `disabled opacity-30`
- Pending state: `useTransition` — button `opacity-50 cursor-wait` during action

**Note on sibling scope:** Reorder operates within same `parent_id` siblings only — arrows disabled when no same-parent sibling exists in that direction.

### 5. Conflict Badge — "⚠ Çakışma"

**Location:** Sayfa Adı cell in tree table rows — inline after page title text

**Trigger:** Page has duplicate keyword text appearing in multiple clusters that both have pages (BLUE-02)

**Markup:**
```tsx
{hasConflict && (
  <span className="ml-2 text-xs px-1.5 py-0.5 rounded bg-red-500/20 text-red-400 shrink-0">
    ⚠ Çakışma
  </span>
)}
```

Color: `bg-red-500/20` background, `text-red-400` text — consistent with destructive semantic
Positioned: inline-flex after title, `shrink-0` so it doesn't wrap or push title

### 6. Keyword Eşleme Tab — Layout

**Tab content rendered when `tab === 'mapping'`**

**Section A: Eşleşen Keyword'ler**

Table with 4 columns:

| Column | Width | Content |
|--------|-------|---------|
| Sayfa Adı | flex-1 | Page title, `text-sm font-normal` |
| Odak Keyword | flex-1 | `focus_keyword` text, `text-sm text-muted-foreground` |
| Küme Keyword'leri | flex-2 | Comma-separated keyword list, `text-xs text-muted-foreground` truncated |
| Intent | w-28 | `IntentBadge` component (reused from Phase 5/6) |

Header: `bg-muted/50 border-b border-border text-xs text-muted-foreground font-normal`
Rows: `border-b border-border last:border-0 text-sm hover:bg-muted/30 transition-colors`
Container: `rounded-md border border-border overflow-hidden`

Conflict badge on Sayfa Adı cell: `⚠ Çakışma` inline badge if page has mapping conflict (same pattern as tree table)

**Section B: Eşleşmeyenler**

Heading: `text-sm font-semibold text-amber-400` — "Eşleşmeyen Keyword'ler ({N})"

Only shown when `unmappedKeywords.length > 0`.

Warning banner above list:
```tsx
<div className="rounded-md border border-amber-500/30 bg-amber-500/10 px-4 py-3 text-sm text-amber-400">
  Bu keyword'ler henüz bir sayfaya bağlı değil. Küme oluşturup "Kümelerden Oluştur" ile sayfa atayın.
</div>
```

Keyword list: flat `<ul>` with `text-sm text-muted-foreground` items, `py-1` spacing, keyword text only.

Empty state for Eşleşmeyenler (all mapped): not rendered — section hidden entirely.

## Interaction States

### GeneratePagesDialog row interactions

| State | Visual |
|-------|--------|
| Normal include row | White bg, checkbox checked, input editable |
| "Zaten var" row | `bg-amber-500/10`, checkbox unchecked, input disabled `opacity-50` |
| Unchecked by user | Normal bg, checkbox unchecked, input editable but greyed `opacity-60` |
| Pending (submit) | All inputs disabled, "Oluşturuluyor…" on button |

### Tree table row interactions

| State | Visual |
|-------|--------|
| Default | `text-sm`, slug in `text-muted-foreground font-mono text-xs` |
| Hover | `hover:bg-muted/30 transition-colors` |
| With conflict | Page name + `⚠ Çakışma` badge inline |
| Reordering | Row opacity unchanged; button enters `opacity-50 cursor-wait` |

### Tab switcher

| State | Visual |
|-------|--------|
| Active | `bg-secondary text-foreground font-semibold` |
| Inactive | `text-muted-foreground font-normal hover:text-foreground` |
