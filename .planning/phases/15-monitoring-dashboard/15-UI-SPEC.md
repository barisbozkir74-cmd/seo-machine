## Layout

### Page Structure

Route: `/projeler/[id]/izleme`

```
[ProjectNav left col — w-64 shrink-0]  [Main content — flex-1 min-w-0]
                                          ├─ Page title: "İzleme"
                                          ├─ Period tab bar: 7G | 28G | 90G
                                          ├─ Section: Cluster Performansı
                                          │   └─ ClusterSummaryTable
                                          └─ Section: Sayfa Performansı
                                              └─ PageMetricsTable (with decay badges)
```

- Two-column project page layout: `w-64 shrink-0` left nav + `flex-1 min-w-0` right content — carries from Phase 2 pattern (`page.tsx` proje detay sayfası).
- Period tab bar renders as three `<button>` elements with `?period=7|28|90` query param on click. Active tab: `bg-secondary text-foreground font-medium`. Inactive tab: `text-muted-foreground hover:text-foreground`. No router push — replaceState or `<Link>` with query param.
- Default period: `28` (pre-selected when no `?period` param present).
- Both section tables respond to the same period selection.

### ClusterSummaryTable

Columns (in order): Cluster Adı | Tıklama | Gösterim | CTR | Ort. Pozisyon

- Sorted by `SUM(clicks)` descending (highest traffic cluster first).
- Cluster Adı: `text-sm font-medium text-foreground`.
- Metric values: `text-sm tabular-nums text-foreground`.
- CTR: formatted as percentage, e.g. `3.2%`.
- Ort. Pozisyon: 1 decimal place, e.g. `12.4`.
- Row background: `bg-card`. Header: `bg-muted text-muted-foreground text-xs font-medium uppercase tracking-wide`.
- No row-level click action (read-only table).
- Empty state: if no clusters have GSC data → show empty state message (see Copywriting Contract).

### PageMetricsTable

Columns (in order): Sayfa URL | Tıklama | Gösterim | Ort. Pozisyon | Değişim | Durum

- Sorted by `clicks` descending.
- Sayfa URL: truncated with `truncate max-w-[240px]`, `text-sm text-muted-foreground`. Full URL in `title` attribute for tooltip.
- Tıklama: `text-sm tabular-nums`, blue-tinted value via `text-[#3b82f6]` for top 3 rows by clicks (visual emphasis only, not semantic).
- Değişim (delta_position): show as `+5.2` (positive = worse) or `-2.1` (negative = better). Color: positive delta → `text-red-400`, negative delta → `text-emerald-400`, zero → `text-muted-foreground`.
- Durum column: decay badge rendered only when `delta_position >= +5` AND `impressions > 10`. Badge: `bg-red-500/15 text-red-400 border border-red-500/30 text-xs rounded-full px-2 py-0.5` with text "Düşüş". Healthy rows: no badge (empty cell).
- Row hover: `hover:bg-muted/50 transition-colors`.
- Header: same pattern as ClusterSummaryTable header.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Period tab click | Replace `?period` query param via `router.push` (shallow); page.tsx reads searchParam, refetches server data; selected tab highlights immediately |
| Decay badge hover | No tooltip required (badge label "Düşüş" is self-describing); title attribute on row shows full URL |
| Cluster row | No click action — read-only |
| Page row | No click action — read-only (link to page package is Phase 16 scope) |
| GSC not connected | Full-page empty state with CTA linking to project settings — no table rendered |

## States

| View | Condition | Rendering |
|------|-----------|-----------|
| Loading | Server component fetching | Skeleton rows (`animate-pulse bg-muted h-4 rounded`) in both tables |
| Empty — no GSC | `gsc_property_url IS NULL` | Full section replaced by empty state card with link to proje bilgileri |
| Empty — no metrics | GSC connected, no rows in `gsc_metrics` for period | Empty state message inside table area |
| Populated | Data present | ClusterSummaryTable + PageMetricsTable rendered |
| Decay present | >= 1 page with `delta_position >= +5` AND `impressions > 10` | DecayBadge inline on affected rows; no modal or banner needed |
