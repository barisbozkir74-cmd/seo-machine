## Spacing Scale

Projedeki mevcut Tailwind token örüntüsünden türetildi. Yeni spacing tanımlanmaz; aşağıdaki değerler mevcut kullanımdan çekildi.

| Token | Tailwind class | Pixel karşılık | Kullanım yeri |
|-------|---------------|----------------|---------------|
| xs | gap-1 / p-1 | 4px | İkon boşlukları, inline padding |
| sm | gap-2 / px-2 py-1 | 8px | Kompakt satır elemanları |
| md | px-3 py-2 | 12px / 8px | Keyword satır padding |
| lg | px-3 py-3 | 12px / 12px | Cluster header padding |
| xl | px-6 py-3 | 24px / 12px | Sayfa toolbar padding |
| 2xl | gap-4 | 16px | Card grid gap |

**Exceptions:**
- 12px (px-3/py-3) — mevcut projenin compact satır padding'i (`ClusterPanel.tsx`, `page.tsx`). 8px ile 16px arası geçiş değeri; tüm layout'ları yeniden yazmayı gerektirmeden tutarlılık sağlar.
- Touch target minimum 36px yükseklik (h-9 = 36px) — mevcut Button default.
- Overlay panel inner scroll: `max-h` değerleri viewport bağımlı, sabit token dışında.

### Cluster Adı — Inline Edit Durumu

Tıklandığında `<span>` yerini `<input>` alır. Enter veya blur ile kaydedilir. Escape ile iptal edilir.

```
<input
  autoFocus
  className="flex-1 h-6 bg-transparent border-0 border-b border-border text-sm font-semibold focus:outline-none focus:border-foreground px-0"
  value={editValue}
  onChange={(e) => setEditValue(e.target.value)}
  onKeyDown={(e) => {
    if (e.key === 'Enter') saveClusterName()
    if (e.key === 'Escape') cancelEdit()
  }}
  onBlur={saveClusterName}
/>
```

**Not:** İsim değişikliği status kararından bağımsızdır (D-02). Kullanıcı isme çift tıkladığında edit aktif olur (tek tıkla cluster seçimi çakışmasını önler).

## Inline Cluster Name Edit — Etkileşim Akışı

1. Kullanıcı cluster adına **çift tıklar** → `<span>` yerini `<input>` alır, `autoFocus`.
2. Kullanıcı metni düzenler.
3. **Enter** veya **blur**: `PATCH /api/clusters/{id}` ile isim güncellenir → `<input>` yerini `<span>` alır.
4. **Escape**: Değişiklik iptal edilir, orijinal isim geri yüklenir.
5. Boş string ile kaydedilmeye çalışılırsa: Kayıt engellenir, input kırmızı border alır (`border-destructive`) ve "Küme adı boş bırakılamaz" tooltip gösterilir.

```
// Validation hata durumu
className="flex-1 h-6 bg-transparent border-0 border-b border-destructive text-sm font-semibold focus:outline-none px-0"
```
