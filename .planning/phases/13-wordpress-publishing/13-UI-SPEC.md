# Phase 13 — UI Design Contract

> Visual and interaction contract for Phase 13: WordPress Publishing.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui v4 |
| Preset | base-mira (from components.json) |
| Component library | @base-ui/react (NOT @radix-ui) |
| Icon library | @hugeicons/react — free tier only |
| Font | Geist Sans (--font-sans) / Geist Mono (--font-mono) |

**Critical constraints (locked from prior phases — STATE.md):**
- Tailwind v4 CSS-first: `tailwind.config.ts` yoktur. Tüm tema özelleştirmeleri `globals.css` CSS custom property olarak yazılır.
- Dark mode: `html` elementinde statik `className="dark"` — toggle yok, light mode render edilmez.
- `font-medium` class YASAKTIR. Ağırlık geçişi için `font-normal` (400) ve `font-semibold` (600) kullanılır.
- `Badge`: `variant` prop kullanılmaz — renk `className` ile doğrudan atanır.
- `DialogTrigger`: `asChild` kullanılmaz — `render={<Button />}` prop pattern kullanılır.

## Spacing Scale

Declared values (multiples of 4 only — inherited from Phase 12 contract):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | İkon gap'leri, badge iç padding |
| sm | 8px | Buton iç padding, kart içi sıkışık boşluk |
| md | 16px | Varsayılan element spacing, kart padding |
| lg | 24px | Bölüm grupları arası gap, header padding |
| xl | 32px | Layout gap, sağ içerik area padding |
| 2xl | 48px | Sayfa üst/alt padding |
| 3xl | 64px | Sayfa düzeyinde büyük boşluk |

Exceptions:
- Touch target minimum 44px — "Kaydet" ve "WordPress'e Gönder" butonları için `min-h-[44px]`
- Password input'ta maskeleme ikonu alanı: sağ padding 40px (`pr-10`)

## Layout Contract

### 1. WordPress Bağlantısı Bölümü — /projeler/[id]

Mevcut proje detay sayfası 2-sütun layout'una eklenir. Sağ içerik area'sında `ProjectInfoSection`'ın altına yeni bir bölüm olarak render edilir.

```
┌──────────────────────────────────────────────────────────┐
│  h1: {Proje Adı}                                         │
│  p: {domain}                                             │
├─────────────────┬────────────────────────────────────────┤
│  SOL NAV        │  SAĞ İÇERİK                            │
│  w-64 shrink-0  │  flex-1 min-w-0 overflow-y-auto p-8   │
│                 │                                         │
│  [nav items]    │  h2: Proje Bilgileri                   │
│                 │  [ProjectInfoSection]                   │
│                 │                                         │
│                 │  <Separator />                          │
│                 │                                         │
│                 │  h2: WordPress Bağlantısı              │
│                 │  [WordPressConnectionSection]           │
│                 │   ├── Bağlantı durumu badge            │
│                 │   ├── wp_url input                     │
│                 │   ├── wp_app_password input (masked)    │
│                 │   └── [Kaydet] butonu                  │
└─────────────────┴────────────────────────────────────────┘
```

**WordPressConnectionSection yapısı:**

```
┌─── WordPress Bağlantısı ─────────────────────────────┐
│  [Badge: "Bağlı" (emerald) / "Yapılandırılmadı" (slate)]
│                                                        │
│  WordPress URL                                         │
│  [https://example.com ___________________________]     │
│                                                        │
│  Uygulama Şifresi                                      │
│  [xxxx xxxx xxxx xxxx ____________________] [👁]       │
│                                                        │
│  Uygulama Şifresini WordPress Admin > Profil >         │
│  Uygulama Şifrelerinden oluşturun.                     │
│                                                        │
│                              [Kaydet]                  │
└────────────────────────────────────────────────────────┘
```

- Bölüm başlığı: `h2` — 16px, font-semibold
- Bağlantı durumu badge'i: `className` ile renk, `variant` prop kullanılmaz
  - Bağlı: `className="bg-emerald-500/20 text-emerald-400"`
  - Yapılandırılmadı: `className="bg-slate-800 text-slate-400"`
- URL input: type="url", placeholder="https://example.com"
- Şifre input: type="password" başlangıçta; göster/gizle toggle ile type="text"
- Göster/gizle toggle: input sağında absolute konumlu ghost `<Button size="icon-sm" variant="ghost" />`
- Yardım metni: `text-xs text-muted-foreground` — şifre alanının altında
- Kaydet butonu: `primary` variant, sağa hizalı, `min-h-[44px]`

### 2. PublishDialog — Content Studio HtmlReadyBanner'a ek

`HtmlReadyBanner.tsx` genişletilir. Mevcut yeşil banner'a "WordPress'e Gönder" butonu eklenir.

**Güncellenmiş HtmlReadyBanner görünümü:**

```
┌── sticky bottom-0 ──────────────────────────────────────┐
│  ✓ HTML Çıktısı Hazır                                   │
│  Tüm bölümler onaylandı. İçerik WordPress'e hazır.       │
│                               [WordPress'e Gönder]      │
└──────────────────────────────────────────────────────────┘
```

- WordPress bağlantısı yapılandırılmadıysa: buton disabled + tooltip/title="Önce WordPress bağlantısını yapılandırın"
- WordPress bağlantısı varsa: buton aktif, tıklandığında `PublishDialog` açılır

**WP yayınlandıktan sonra HtmlReadyBanner görünümü:**

```
┌── sticky bottom-0 ──────────────────────────────────────┐
│  ✓ WordPress'te Yayında                                  │
│  Yayın tarihi: {tarih} · [Sayfayı Görüntüle ↗]         │
└──────────────────────────────────────────────────────────┘
```

- Arka plan: aynı — `bg-emerald-500/10 border border-emerald-500/30`
- Post URL linki: `target="_blank" rel="noopener noreferrer"`

### 3. PublishDialog

`Dialog` + `DialogContent` + `DialogHeader` + `DialogFooter` pattern. `DialogTrigger` render prop pattern kullanılır (asChild yasak).

```
┌── Dialog (max-w-sm) ──────────────────────────────────┐
│  WordPress'e Gönder                          [×]       │
│  ──────────────────────────────────────────────────── │
│  Sayfa: {focus_keyword veya title}                     │
│                                                        │
│  (●) Hemen Yayınla                                     │
│      İçerik hemen yayınlanır.                          │
│                                                        │
│  ( ) Taslak Kaydet                                     │
│      WordPress taslak olarak kaydedilir, yayınlanmaz. │
│                                                        │
│  ──────────────────────────────────────────────────── │
│                      [Vazgeç]  [Gönder]               │
└────────────────────────────────────────────────────────┘
```

**RadioGroup yapısı:**

- `Hemen Yayınla` varsayılan seçili
- Her seçenek: radio input + label + açıklama metni (12px, muted-foreground)
- RadioGroup için `<fieldset>` ile `<legend className="sr-only">Yayın seçeneği</legend>` — erişilebilirlik

**Dialog durum yönetimi:**

| Durum | Gönder Butonu | İçerik |
|-------|--------------|--------|
| Hazır | Aktif, "Gönder" | RadioGroup görünür |
| Gönderiliyor | Disabled, spinner + "Gönderiliyor..." | RadioGroup disabled |
| Başarılı | — | Dialog otomatik kapanır |
| Hata | Aktif, "Tekrar Dene" | Hata mesajı görünür (`text-destructive`) |

**Spinner:** `animate-spin` ile Hugeicons `Loading03Icon` (16px) — "Gönderiliyor..." metninin solunda

## Interaction Contracts

### Kimlik Bilgisi Formu (WordPressConnectionSection)

1. Sayfa ilk yüklendiğinde Vault'ta kayıt var mı kontrol edilir (Server Component SSR).
2. Kayıt varsa: input'lar placeholder değer gösterir (`"••••••••••••"` şifre için), badge "Bağlı".
3. Kayıt yoksa: input'lar boş, badge "Yapılandırılmadı".
4. Kullanıcı herhangi bir input'a yazdığında "Kaydet" butonu aktif hale gelir.
5. "Kaydet" tıklandığında: client-side URL format validate → Server Action `saveWordPressCredentials()` çağrısı → Vault write.
6. Başarıda: badge güncellenir "Bağlı" → `revalidatePath()` ile sayfa refresh.
7. Hatada: hata mesajı input altında `text-xs text-destructive` ile gösterilir.

**Şifre göster/gizle:**
- `type="password"` başlangıçta.
- Toggle butonu tıklandığında `type="text"` geçer, ikon `EyeOff01Icon` → `Eye01Icon` değişir.
- Focus input'tan ayrılmaz — toggle `e.preventDefault()` kullanır.

### PublishDialog Akışı

1. "WordPress'e Gönder" tıklanır → Dialog açılır.
2. Varsayılan seçim: "Hemen Yayınla".
3. Kullanıcı seçim değiştirebilir (Taslak Kaydet).
4. "Gönder" tıklanır:
   - Buton disabled + spinner gösterilir.
   - Server Action `publishToWordPress(projectId, pageId, status)` çağrısı.
   - Action: Vault → wp_url + wp_app_password oku → plugin algıla → WP REST POST.
5. Başarıda:
   - Dialog kapanır.
   - `HtmlReadyBanner` "WordPress'te Yayında" / "WordPress Taslak Olarak Kaydedildi" görünümüne geçer.
   - `revalidatePath()` ile sayfa güncel kalır.
6. Hatada:
   - Dialog kapanmaz.
   - Hata mesajı dialog içinde `DialogFooter` üstünde `text-xs text-destructive` ile görünür.
   - "Gönder" butonu "Tekrar Dene" olarak değişir, aktif hale gelir.

### WP Yayın Durumu — Sayfa Paketi Listesi

`page_packages` `wp_status` alanına göre her sayfa satırında ek badge gösterilir:
- `wp_status = 'publish'`: `className="bg-emerald-500/20 text-emerald-400"` — "WP: Yayında"
- `wp_status = 'draft'`: `className="bg-slate-800 text-slate-400"` — "WP: Taslak"
- `wp_status = null`: badge render edilmez

## State Machine Referansı

### Kimlik Bilgisi Bağlantı Durumu

```
not-configured ──[Kaydet başarı]──▶ connected
    ▲                                   │
    └───────[Kaydet (üzerine yaz)]──────┘
```

### WP Yayın Durumu (page_packages.wp_status)

```
null ──[Taslak Kaydet]──▶ draft
null ──[Hemen Yayınla]──▶ publish
draft ──[Hemen Yayınla]──▶ publish
```

Not: Yayından geri alma bu fazda yok (out of scope).

## Accessibility

- `WordPressConnectionSection` form elemanları: her input `<label>` ile ilişkilendirilir (`htmlFor` + `id`).
- Şifre alanı: `aria-label="Uygulama Şifresi"`, toggle butonu `aria-label="Şifreyi göster"` / `"Şifreyi gizle"`.
- `PublishDialog`: `DialogTitle` ile başlık tanımlanır; RadioGroup `<fieldset>` + `<legend className="sr-only">` kullanır.
- Bağlantı durumu badge: `aria-live="polite"` ile ekran okuyucuya güncelleme iletilir.
- Gönderim spinner: `aria-busy="true"` gönder butonunda, `aria-label="Gönderiliyor"`.
- "Sayfayı Görüntüle" linki: `aria-label="WordPress'teki sayfayı yeni sekmede görüntüle"`.
