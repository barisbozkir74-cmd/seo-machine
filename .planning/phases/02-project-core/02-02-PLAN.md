**1. `src/app/(dashboard)/projeler/page.tsx` dosyasını oluştur:**

Bu bir Server Component (async function). Sayfada iki temel durum var: boş (proje yok) ve dolu (tablo göster).

```typescript
import { createClient } from '@/lib/supabase/server'
import Link from 'next/link'
import { Button } from '@/components/ui/button'
import {
  Table, TableBody, TableCell, TableHead,
  TableHeader, TableRow

```

**Veri sorgusu:** `projects` tablosunu `created_at` DESC sırasıyla çek. Her proje için aktif stage adını bulmak üzere `stages` tablosuna da sorgu yap (status = 'active' olan stage_name).

Tek sorguda JOIN yapmak yerine iki ayrı Supabase sorgusu kullan:
1. `supabase.from('projects').select('*').order('created_at', { ascending: false })`
2. Her proje için stages'ten aktif stage'i çek — ya toplu bir sorgu ile (`supabase.from('stages').select('project_id, stage_name').eq('status', 'active').in('project_id', projectIds)`) ya da projelerle birlikte `.select('*, stages!inner(stage_name, status)')` ile.

Tercih et: `supabase.from('projects').select('id, name, domain, sector, created_at, stages(stage_name, status)').order('created_at', { ascending: false })`

Stages relation'ından aktif olanı filtrele: `stages.find(s => s.status === 'active')?.stage_name ?? '—'`

**Tablo (projeler.length > 0):**
Sütun sırası: Proje Adı | Domain | Sektör | Aktif Stage | Durum | Oluşturulma

- "Proje Adı" sütunu: `<Link href={/dashboard/projeler/${proje.id}} className="hover:underline">{proje.name}</Link>`
- "Sektör" boşsa: "—"
- "Aktif Stage": stages'ten aktif olanın stage_name'i, yoksa "—"
- "Durum" badge'i: proje tamamlandıysa (tüm stages completed) "Tamamlandı" (emerald), aksi halde "Aktif" (blue)
  - Badge CSS sınıfları UI-SPEC'ten: Aktif = `bg-blue-500/20 text-blue-400 border border-blue-500/30`, Tamamlandı = `bg-emerald-500/20 text-emerald-400 border border-emerald-500/30`
- "Oluşturulma": TR locale date format — `new Date(proje.created_at).toLocaleDateString('tr-TR', { day: 'numeric', month: 'short', year: 'numeric' })`

Tablo satırları tıklanabilir: `className="hover:bg-secondary cursor-pointer"` — ancak tıklama davranışı `<Link>` ile "Proje Adı" sütunundan sağlanır. Tüm satırı tıklanabilir yapmak için Client Component wrapper gerekir; MVP için sadece Proje Adı linkini kullan.

Column headers: `className="text-xs font-normal uppercase text-muted-foreground"`
