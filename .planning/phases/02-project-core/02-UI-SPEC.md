## Spacing Scale

Tailwind v4 CSS-first config — no tailwind.config.ts. Use standard Tailwind spacing utilities. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (p-1) | Icon gaps, badge inner padding, inline icon-text gap |
| sm | 8px (p-2) | Compact element spacing, table cell vertical padding |
| md | 16px (p-4) | Default element spacing, form field gaps, card padding |
| lg | 24px (p-6) | Section padding, modal inner padding |
| xl | 32px (p-8) | Layout gaps, page content padding |
| 2xl | 48px (p-12) | Major section breaks, empty state vertical centering |
| 3xl | 64px (p-16) | Page-level top/bottom spacing |

Exceptions:
- Touch targets (stage transition button, confirmation dialog buttons): minimum 44px height — use `h-11` (44px)
- Stage list items: `py-3` (12px vertical) to maintain density without crowding 10 items

## Typography

Font: Geist Sans via `--font-sans` CSS variable, applied globally via `html { @apply font-sans }`.

| Role | Size | Weight | Line Height | Tailwind class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm font-normal leading-relaxed` |
| Label | 12px | 400 (regular) | 1.4 | `text-xs font-normal leading-snug` |
| Heading | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold leading-tight` |
| Display | 28px | 600 (semibold) | 1.2 | `text-2xl font-semibold leading-tight` |

Rules:
- Body (14px / 400): table cell content, note text, form helper text
- Label (12px / 400): table column headers, stage status badges, form field labels, section sub-labels
- Heading (20px / 600): page titles ("Projeler"), modal titles ("Yeni Proje Oluştur"), detail page project name
- Display (28px / 600): reserved for future dashboard KPI cards — do not use in Phase 2 UI
- Two weights only: 400 (regular) and 600 (semibold). Do not use 700 or 500 in any Phase 2 components.

## Color

All values from `.dark` block in `src/app/globals.css`. The app is dark-mode only.

| Role | CSS Variable | Hex | Usage |
|------|-------------|-----|-------|
| Dominant (60%) | `--background` | `#020817` (Slate 950) | Page background, full-width surfaces |
| Secondary (30%) | `--card` | `#0f172a` (Slate 900) | Cards, modal backgrounds, sidebar, table rows (hover: `--secondary` Slate 800) |
| Accent (10%) | `--primary` | `#f8fafc` (Slate 50) | See reserved list below |
| Destructive | `--destructive` | `#ef4444` (Red 500) | Destructive confirmation dialog only |
| Border | `--border` | `#1e293b` (Slate 800) | Table dividers, card borders, input borders |
| Muted text | `--muted-foreground` | `#64748b` (Slate 500) | Placeholder text, secondary copy, "Bekliyor" badge text |
| Sidebar primary | `--sidebar-primary` | `#3b82f6` (Blue 500) | Active stage indicator, "Aktif" badge |

Accent (`--primary` / `#f8fafc`) reserved for:
1. Primary CTA button fill — "Yeni Proje Oluştur" button in page header
2. Stage transition submit button — "Sonraki Aşamaya Geç" within confirmation dialog
3. Modal submit button — "Oluştur" button inside new project dialog
4. Nothing else — all other interactive elements use secondary/muted variants

Status badge color assignments (discretion decision from CONTEXT.md):
- Aktif: Blue 500 (`#3b82f6`) background with white text — `bg-blue-500/20 text-blue-400 border border-blue-500/30`
- Tamamlandı: Green 500 (`#10b981`) tinted — `bg-emerald-500/20 text-emerald-400 border border-emerald-500/30`
- Bekliyor: Slate muted — `bg-muted text-muted-foreground border border-border`

## Interaction States

### Table Rows
- Default: background transparent
- Hover: `hover:bg-secondary` (Slate 800)
- Active row (navigated to): not applicable (navigation leaves the page)
- Clicking a row navigates to detail page

### Stage List Items (Left Column)
- Completed: checkmark icon (hugeicons: `tick-02` or `check-mark-circle-02`), text `text-muted-foreground line-through` — NO, use `text-emerald-400` without strikethrough (completed stages retain readability)
- Active: circle filled icon, `text-foreground font-semibold`, left border accent `border-l-2 border-blue-500`
- Pending: circle empty icon, `text-muted-foreground`
- Not clickable — stage navigation is driven by transition button, not list item clicks

### Note List (History)
- Each note: timestamp (small, muted) + note body (body text)
- Newest note first
- No editing or deletion of notes (append-only, per D-11 audits table design)
- Max display: show all notes (no pagination in Phase 2; note count will be low)

### Loading States
- Table loading: skeleton rows (3 rows × full width, using `animate-pulse bg-muted rounded`)
- Detail page loading: skeleton for left column (10 items) + skeleton for right content block
- Note submit: button shows loading spinner via `disabled` + spinner icon while Server Action processes
