## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui |
| Preset | base-mira |
| Base color | slate |
| Component library | Radix UI (via shadcn) |
| Icon library | hugeicons |
| Font | Geist Sans (`--font-sans`) / Geist Mono (`--font-mono`) |

**shadcn gate result:** `components.json` mevcut. Kurulu bileşenler:
`alert-dialog`, `badge`, `button`, `card`, `dialog`, `form`, `input`, `label`,

## Spacing Scale

Proje 8-point scale kullanır (mevcut koddan çıkarıldı — kaynak: PagePackageEditor.tsx,
page-metrics-table.tsx, izleme/page.tsx).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Rozet iç padding (`px-2 py-0.5`), ikon aralıkları (`gap-1`) |
| sm | 8px | Buton grupları arası (`gap-2`), label-input aralığı (`space-y-1.5`) |
| md | 16px | Bölüm içi eleman aralığı (`space-y-4`), yatay panel padding (`p-4`) |
| lg | 24px | Bölümler arası (`space-y-6`) |
| xl | 32px | Ana içerik padding (`p-8`) |
| 2xl | 48px | Büyük bölüm araları (`space-y-8`) |
| 3xl | 64px | Sayfa düzeyinde boşluklar |

Exceptions: Sheet bileşeninin genişliği `w-[420px]` — standart dışı ama
drawer mantığı gereği sabit genişlik.

## Typography

Mevcut koddan çıkarılan değerler (kaynak: PagePackageEditor.tsx, page-metrics-table.tsx):

| Role | Size | Weight | Line Height | Class |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (normal) | 1.5 | `text-sm` |
| Label / Table header | 12px | 400 (normal) | 1.4 | `text-xs` |
| Section heading | 14px | 600 (semibold) | 1.2 | `text-sm font-semibold` |
| Page heading | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold` |

Font family: `font-sans` (Geist Sans) — body, labels, headings.
Mono (`font-mono`, Geist Mono) — JSON editor alanları, tabular-nums metrikler.

## Color

Proje dark-first. Tüm token değerleri dark mode CSS değişkenlerinden (globals.css):

| Role | CSS Token | Hex | Usage |
|------|-----------|-----|-------|
| Dominant (60%) | `--background` | `#020817` (Slate 950) | Sayfa zemini |
| Secondary (30%) | `--card` / `--muted` | `#0f172a` (Slate 900) / `#1e293b` (Slate 800) | Kart yüzeyleri, tablo hover, sidebar |
| Accent (10%) | `--primary` | `#f8fafc` (Slate 50) | Birincil aksiyon butonları (Kaydet, Bunu Yükle) |
| Destructive | `--destructive` | `#ef4444` (Red 500) | Yıkıcı aksiyon kopyası ve ikonları |

**Accent yalnızca şu öğelere rezerve edilmiştir:**
- Birincil submit butonu (`Button` default variant): Kaydet, Bunu Yükle, Ekle
- Revizyon listesindeki aktif/vurgulu satır değil — orası `hover:bg-muted/50`

**Semantic renkler (mevcut koddan):**
- `text-emerald-400` — pozitif delta, başarı mesajları
- `text-red-400` — negatif/hata durumu, Düşüş rozeti
- `text-amber-400` — uyarı, karakter limiti aşımı
- `text-muted-foreground` (`#64748b`) — ikincil etiketler, boş metrikler, dash `—`

## Bileşen Envanteri

### MON-03 — PageMetricsTable Genişletmesi

**Etkilenen dosya:** `src/app/(dashboard)/projeler/[id]/izleme/page-metrics-table.tsx`

#### Yeni satır tipi: Imported Page

Imported sayfalar mevcut GSC satırlarıyla aynı tabloya eklenir.
GSC metrikleri olmadığından (clicks, impressions, avgPosition = null):

| Sütun | GSC Satırı | Imported Satır |
|-------|-----------|----------------|
| Sayfa | URL metin | URL metin (aynı) |
| Tıklama | Sayı | `—` (`text-muted-foreground`) |
| Gösterim | Sayı | `—` (`text-muted-foreground`) |
| Ort. Pozisyon | Sayı | `—` (`text-muted-foreground`) |
| Değişim | ±delta | `—` (`text-muted-foreground`) |
| Durum | Düşüş rozeti veya `—` | `İçe Aktarıldı` rozeti (mavi) |

**İçe Aktarıldı rozeti:** `bg-blue-500/15 text-blue-400 border border-blue-500/30 text-xs rounded-full px-2 py-0.5`
(Mevcut Düşüş rozetinin renk şemasıyla tutarlı — kırmızı yerine mavi)

**Boş durum güncellemesi:** Hem GSC satırları hem imported sayfalar boşken:
`"Henüz sayfa verisi yok"` — mevcut `"GSC verisi bulunamadı"` yerine.
(D-02 gereği: pages sekmesi artık GSC gate'siz görünür)

**GSC gate değişikliği (page.tsx):** `!gscConnected` dalında tüm içerik gizlenme
bloğu korunur — ama `pages` sekmesi ve imported pages fetchi bu bloktan bağımsız
hale gelir. Pratik: kullanıcı `?tab=pages` ile gezebilir.

#### Boş durum metni (pages sekmesi, GSC bağlı değil):

```
Başlık: Sayfa verisi bulunamadı
Açıklama: GSC bağlantısı yok — yalnızca içe aktarılan sayfalar listelenir.
```

### PAGE-05-A — PagePackageEditor Toolbar Değişikliği

**Etkilenen dosya:** `src/app/(dashboard)/projeler/[id]/sayfa-paketi/PagePackageEditor.tsx`

**"Geçmiş" butonu konumu:** Header aksiyon satırı sağına eklenir — mevcut
`<div className="flex items-center gap-2 shrink-0">` bloğuna, tüm statü butonlarının
ÖNÜNE (soluna) yerleştirilir. Böylece daima görünür kalır.

**Buton spec:**
```tsx
<Button variant="ghost" size="sm" onClick={() => setHistoryOpen(true)}>
  Geçmiş
</Button>
```
- Variant: `ghost` — primary CTA'lardan ayrışsın
- Size: `sm` — h-9, diğer toolbar butonlarıyla aynı yükseklik (mevcut pattern)
- Yalnızca `pkg !== null` iken gösterilir (package yoksa revision history manasız)
- Disabled: `false` — her zaman tıklanabilir (yükleme durumu sheet içinde)

### PAGE-05-B — RevisionHistorySheet (YENİ bileşen)

**Dosya:** `src/app/(dashboard)/projeler/[id]/sayfa-paketi/RevisionHistorySheet.tsx`

**shadcn Sheet bileşeni** — `npx shadcn add sheet` ile kurulur.

**Açılma yönü:** `side="right"` — editör kapanmaz, yan yana görünür

**Genişlik:** `className="w-[420px]"` — Tailwind arbitrary value

**Header:**
- `SheetTitle`: `"Revizyon Geçmişi"`
- `SheetDescription`: `"Kaydedilen sürümler — bir revizyonu yükleyerek geri alabilirsin."`

**Liste satırı:** Her revision için bir satır:

```
[v{version_num}]  [tarih-saat]  [Önizle butonu]
```

- Version: `text-sm font-semibold text-foreground` — örnek: `v3`
- Tarih: `text-xs text-muted-foreground` — format: `dd.MM.yyyy HH:mm` (tr-TR locale)
- Önizle butonu: `variant="outline" size="sm"` — sağa hizalı

**Satır ayrımı:** `border-b border-border` — mevcut tablo pattern'i ile tutarlı

**Boş durum:** Henüz kayıtlı revizyon yoksa (ilk kayıt henüz yapılmamış):
```
"Henüz kayıtlı revizyon yok. İlk kaydetme işleminde otomatik oluşturulur."
```
`text-sm text-muted-foreground` — ortalanmış, padding: `py-8`

**Yükleme durumu:** Liste fetch edilirken:
```tsx
<div className="w-5 h-5 rounded-full border-2 border-muted border-t-foreground animate-spin mx-auto mt-8" />
```
(Mevcut QA dialog spinner ile tutarlı)

**Hata durumu:**
```
"Revizyon listesi yüklenemedi. Lütfen sayfayı yenile."
```
`text-sm text-red-400` — mevcut hata renk pattern'i

### PAGE-05-C — RevisionPreviewDialog (YENİ bileşen)

**Dosya:** `src/app/(dashboard)/projeler/[id]/sayfa-paketi/RevisionPreviewDialog.tsx`

**shadcn Dialog bileşeni** — zaten kurulu (`dialog.tsx` mevcut)

**Boyut:** `max-w-2xl` — içeriği görüntülemek için geniş

**Header:**
- `DialogTitle`: `"Revizyon {version_num} — Önizleme"`
- `DialogDescription`: `"Bu sürüm {tarih} tarihinde kaydedildi. Salt okunur görünüm."`

**İçerik alanı:**
- Snapshot JSON alanları read-only olarak gösterilir
- Aynı `Field` bileşeni `disabled={true}` ile — mevcut editor pattern
- Scroll: `max-h-[60vh] overflow-y-auto` içerik sarmalayıcı

**Footer aksiyonları:**
```
[Kapat]    [Bunu Yükle]
```
- Kapat: `variant="ghost" size="sm"` — `DialogClose` wrapper
- Bunu Yükle: `variant="default" size="sm"` — primary CTA, modal kapanır ve
  revision verisi editor state'e yüklenir (D-06 gereği — kaydedilmez)

**Yükleme state'i (Bunu Yükle tıklandıktan sonra):**
- Buton label: `"Yükleniyor..."` + `disabled={true}`
- Modal kapanınca editor alanları snapshot değerleriyle dolar

## Etkileşim Akışları

### MON-03 Akışı

```
izleme/page.tsx
  ├── gscConnected=true → mevcut akış (clusters default tab)
  │   pages sekmesi → PageMetricsTable
  │     ├── GSC satırları (normal)
  │     └── Imported satırlar (GSC metrikleri = dash, İçe Aktarıldı rozeti)
  └── gscConnected=false → clusters+recovery gizli
      pages sekmesi (?tab=pages ile) → PageMetricsTable
        └── Imported satırlar + boş state kopya
```

### PAGE-05 Akışı (D-04 + D-05 + D-06)

```
PagePackageEditor (header)
  └── [Geçmiş] butonu (ghost, sm) — pkg mevcut iken görünür
        ↓ onClick
      RevisionHistorySheet açılır (side=right)
        ├── [Yükleniyor spinner]
        ├── Revision listesi (v1, v2, v3...)
        │   └── Her satır: [Önizle] butonu
        │         ↓ onClick
        │       RevisionPreviewDialog açılır
        │         ├── Read-only snapshot alanları
        │         └── [Bunu Yükle] CTA
        │               ↓ onClick
        │             Dialog kapanır
        │             Sheet kapanır
        │             Editor alanları snapshot değerleriyle güncellenir
        │             (kaydedilmez — kullanıcı "Kaydet" basmayı bekler)
        └── Boş durum: "Henüz kayıtlı revizyon yok..."
```

**Kaydet → Revision otomatik tetiklenme (D-04):**
```
[Kaydet] tıklanır
  → server action: mevcut state'i page_package_revisions'a yazar
  → UPDATE page_packages
  → router.refresh()
```
Bu akış UI'da görünmez — arka planda sessizce gerçekleşir.

| Bunu Yükle CTA | `Bunu Yükle` |
| Bunu Yükle yüklenirken | `Yükleniyor...` |
| Sheet boş durum | `Henüz kayıtlı revizyon yok. İlk kaydetme işleminde otomatik oluşturulur.` |
| Sheet hata | `Revizyon listesi yüklenemedi. Lütfen sayfayı yenile.` |
